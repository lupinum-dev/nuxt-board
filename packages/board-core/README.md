# @lupinum/board-core

Headless engine for node-based boards: pure state reducer, action log, command/event layer, ephemeral interaction state, plugin host. Framework-agnostic — no DOM, no framework, no rendering. Vue/Nuxt bindings live in `@lupinum/vue-board` and `@lupinum/nuxt-board`.

See [`ARCHITECTURE.md`](../../ARCHITECTURE.md) for the layer model and how actions flow through the system.
