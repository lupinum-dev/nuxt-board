## Engine

The engine is the single source of truth for camera, nodes, selection, interaction state, and commands.

## Board nodes

Nodes are immutable records with geometry, type, data, visibility, and optional parent relationships.

## Commands

Mutation goes through engine commands such as `createNode`, `updateNode`, `moveNode`, `deleteSelected`, and `zoomToFit`. Plugins hook into those commands instead of reimplementing board state.

## Rendering

`BoardRoot` subscribes to engine state and renders the current board. Custom renderers only replace node content; they do not own the command system.
