## Shortcut reference

::accordion
::accordion-item{label="Selection" icon="i-lucide-mouse-pointer-2"}
:kbd{value="meta"} :kbd{value="A"} selects all visible, unlocked nodes.

:kbd{value="Escape"} clears the selection and ends the current interaction.
::

::accordion-item{label="Editing" icon="i-lucide-pencil"}
:kbd{value="Enter"} begins text editing on a single selected node.

:kbd{value="Delete"} and :kbd{value="Backspace"} delete the selection.
::

::accordion-item{label="Clipboard" icon="i-lucide-copy"}
:kbd{value="meta"} :kbd{value="C"} copies.

:kbd{value="meta"} :kbd{value="V"} pastes.

:kbd{value="meta"} :kbd{value="D"} duplicates.
::

::accordion-item{label="Navigation" icon="i-lucide-move"}
:kbd{value="ArrowUp"} / :kbd{value="ArrowDown"} / :kbd{value="ArrowLeft"} / :kbd{value="ArrowRight"} nudge the selection.

:kbd{value="Shift"} plus an arrow key nudges by a major step.

:kbd{value="meta"} :kbd{value="0"} zooms to 100%.

:kbd{value="meta"} :kbd{value="1"} zooms to fit.
::

::accordion-item{label="History" icon="i-lucide-history"}
Requires the history plugin.

:kbd{value="meta"} :kbd{value="Z"} undoes.

:kbd{value="meta"} :kbd{value="shift"} :kbd{value="Z"} or :kbd{value="meta"} :kbd{value="Y"} redoes.
::

::

## Editor pass-through

When a `<textarea>` or `contenteditable` element is focused, board shortcuts are suppressed so typing works normally. The `data-editor="true"` attribute marks elements as editor targets.
