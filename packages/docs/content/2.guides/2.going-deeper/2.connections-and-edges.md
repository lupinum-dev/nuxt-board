## Setup

Install the connections plugin during engine creation:

```ts
import { createBoardEngine } from '@lupinum/board-core'
import { connectionPlugin } from '@lupinum/board-connections'

const engine = createBoardEngine({
  plugins: [connectionPlugin({ routing: 'bezier' })],
})
```

---

## Creating Edges

```ts
const edge = engine.ext.connections.createEdge({
  from: sourceNodeId,
  to: targetNodeId,
  label: 'depends on',
  data: {},
})
```

### With anchors

Specify where the edge attaches on each node:

```ts
engine.ext.connections.createEdge({
  from: nodeA,
  to: nodeB,
  fromAnchor: { side: 'right', offset: 0.5 },   // middle of right edge
  toAnchor: { side: 'left', offset: 0.5 },       // middle of left edge
  data: {},
})
```

Anchor `offset` is 0–1 along the side (0.5 = center). If omitted, the connection layer auto-picks the best side from node geometry, keeps it stable while nodes move, and attaches at the center of that side.

---

## Querying Edges

```ts
// All edges
const edges = engine.ext.connections.getEdges()

// Edges from a specific node
const outgoing = engine.ext.connections.getEdgesFrom(nodeId)

// Edges to a specific node
const incoming = engine.ext.connections.getEdgesTo(nodeId)

// Edges between two nodes
const between = engine.ext.connections.getEdgesBetween(nodeA, nodeB)

// A specific edge
const edge = engine.ext.connections.getEdge(edgeId)
```

---

## Updating Edges

Reconnect or restyle an existing edge with `updateEdge()`:

```ts
engine.ext.connections.updateEdge(edgeId, {
  to: otherNodeId,
  toAnchor: undefined, // clear explicit anchor so the new node side auto-resolves
})
```

The connection layer uses the same API internally when you drag an endpoint handle to another node.

---

## Deleting Edges

```ts
engine.ext.connections.deleteEdge(edgeId)
```

Edges are also automatically deleted when either endpoint node is removed.

## Rendering with BoardConnectionLayer

Place `BoardConnectionLayer` inside the `viewport` slot of `BoardRoot`:

```vue
<script setup lang="ts">
import { BoardRoot } from '@lupinum/vue-board'
import { BoardConnectionLayer } from '@lupinum/board-connections'
</script>

<template>
  <BoardRoot :engine="engine">
    <template #viewport>
      <BoardConnectionLayer />
    </template>
  </BoardRoot>
</template>
```

Hover an edge or select it to reveal draggable endpoint handles. Drag either end onto another node to reconnect it. Dropping the handle on empty space cancels the reconnect.

### Routing styles

| Style | Description |
| --- | --- |
| `'bezier'` | Smooth cubic bezier curve (default). |
| `'smooth-step'` | Rounded orthogonal connector. |
| `'step'` | Right-angle stepped path. |
| `'straight'` | Direct straight line. |

```vue
<BoardConnectionLayer routing="step" />
```

### Custom edge rendering

Use the `edge` slot for full control over edge appearance:

```vue
<BoardConnectionLayer>
  <template #edge="{ edge, route }">
    <path :d="route.path" stroke="#3b82f6" stroke-width="2" fill="none" />
    <text :x="route.labelPoint.x" :y="route.labelPoint.y" text-anchor="middle">
      {{ edge.label }}
    </text>
  </template>
</BoardConnectionLayer>
```

## Events

```ts
engine.on('edge:created', (edge) => {
  console.log('Edge created:', edge.from, '→', edge.to)
})

engine.on('edge:updated', (edge, prev) => {
  console.log('Edge moved from', prev.to, 'to', edge.to)
})

engine.on('edge:deleted', (edgeId) => {
  console.log('Edge deleted:', edgeId)
})
```
