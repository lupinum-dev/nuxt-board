## Plugin Interface

A plugin has a name and an `install` function:

```ts
import type { BoardPlugin, BoardPluginContext } from '@lupinum/board-core'

const myPlugin: BoardPlugin = {
  name: 'my-plugin',
  install(ctx: BoardPluginContext) {
    // Set up the plugin using the context
  },
}
```

---

## Installing Plugins

During engine creation:

```ts
const engine = createBoardEngine({
  plugins: [myPlugin],
})
```

Or at runtime:

```ts
engine.use(myPlugin)
```

---

## The Plugin Context

The `install` function receives a `BoardPluginContext` — the full `BoardEngine` interface plus three additional methods:

### emit

Emit events on the engine. Use for custom events or to notify about plugin-specific state changes:

```ts
ctx.emit('my-plugin:activated', { some: 'data' })
```

### extend

Register an API extension on `engine.ext`:

```ts
ctx.extend('myPlugin', {
  doSomething() { /* ... */ },
  getValue() { return 42 },
})

// Users access it as:
engine.ext.myPlugin.doSomething()
```

### runCommand

Execute operations through the full command pipeline (middleware, events, invariants). This ensures your plugin's operations appear in traces, are interceptable by middleware, and are captured by history:

```ts
ctx.runCommand('myPlugin:create', [data], () => {
  // The actual mutation
  return result
})
```

## Example: Auto-Save Plugin

A plugin that serializes the board after every change:

```ts
import type { BoardPlugin } from '@lupinum/board-core'
import { jsonCanvasSerializer } from '@lupinum/board-serializer'

function autoSavePlugin(options: { key: string; debounceMs?: number }): BoardPlugin {
  return {
    name: 'auto-save',
    install(ctx) {
      let timer: ReturnType<typeof setTimeout> | null = null
      const delay = options.debounceMs ?? 1000

      function save() {
        const json = jsonCanvasSerializer.export(ctx)
        localStorage.setItem(options.key, json)
      }

      ctx.on('command:after', (name) => {
        // Skip camera/interaction commands
        if (name.startsWith('zoom') || name.startsWith('pan') || name.startsWith('begin')) {
          return
        }
        if (timer) clearTimeout(timer)
        timer = setTimeout(save, delay)
      })

      ctx.extend('autoSave', {
        saveNow: save,
      })
    },
  }
}
```

### TypeScript: Type-safe extensions

Use module augmentation so `engine.ext.autoSave` is typed:

```ts
declare module '@lupinum/board-core' {
  interface BoardEngineExtensions {
    autoSave: { saveNow: () => void }
  }
}
```

## Plugin Cleanup

Return a cleanup function from `install()` if your plugin needs teardown:

```ts
const myPlugin: BoardPlugin = {
  name: 'my-plugin',
  install(ctx) {
    const interval = setInterval(() => { /* ... */ }, 5000)
    return () => clearInterval(interval)
  },
}
```

## Official Plugins

| Package | Extension key | What it adds |
| --- | --- | --- |
| `@lupinum/board-history` | `ext.history` | Undo/redo with debouncing. |
| `@lupinum/board-connections` | `ext.connections` | Edges between nodes. |

The minimap, selection, and serializer packages are composables/utilities — not plugins.
