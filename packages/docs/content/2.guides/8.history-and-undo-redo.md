## Setup

```ts
import { createBoardEngine } from '@lupinum/board-core'
import { historyPlugin } from '@lupinum/board-history'

const engine = createBoardEngine({
  plugins: [historyPlugin({ maxSteps: 100, debounceMs: 300 })],
})
```

---

## Undo and Redo

```ts
engine.ext.history.undo()
engine.ext.history.redo()
```

### Check availability

```ts
if (engine.ext.history.canUndo()) {
  engine.ext.history.undo()
}
```

### Read state

```ts
const state = engine.ext.history.getState()
console.log(`${state.undoDepth} undo / ${state.redoDepth} redo steps`)
```

### Clear history

```ts
engine.ext.history.clear()
```

---

## Debouncing

Rapid changes (like dragging a node) are coalesced into a single undo step. The `debounceMs` option controls the window — a new history entry is only pushed when no commands fire for this duration.

Set `debounceMs: 0` for testing to disable debouncing.

---

## Excluded Commands

Camera and interaction commands are excluded from history by default — they don't create undo steps:

`panBy`, `panTo`, `zoomAt`, `zoomTo`, `zoomToFit`, `zoomToNodes`, `beginPan`, `beginNodeDrag`, `beginResize`, `beginBoxSelect`, `beginTextEdit`, `endInteraction`

Add more exclusions via the `exclude` option:

```ts
historyPlugin({ exclude: ['myCustomCommand'] })
```

---

## Connection-Aware Restoration

When both `historyPlugin` and `connectionPlugin` are installed, the history plugin automatically captures and restores edge state. Undoing a node deletion also restores its connected edges.

---

## Keyboard Shortcuts

`BoardRoot` handles undo/redo shortcuts automatically:

| Key | Action |
| --- | --- |
| `Ctrl/Cmd + Z` | Undo |
| `Ctrl/Cmd + Shift + Z` | Redo |
| `Ctrl/Cmd + Y` | Redo |

---

## Events

```ts
engine.on('history:push', (entry) => console.log('New step:', entry.label))
engine.on('history:undo', () => console.log('Undo'))
engine.on('history:redo', () => console.log('Redo'))
engine.on('history:clear', () => console.log('History cleared'))
```

## Example: Undo/Redo Buttons

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { useBoardEngine } from '@lupinum/vue-board'

const { engine } = useBoardEngine()
const depth = ref(0)

engine.on('history:push', () => depth.value = engine.ext.history.getState().undoDepth)
engine.on('history:undo', () => depth.value = engine.ext.history.getState().undoDepth)
engine.on('history:redo', () => depth.value = engine.ext.history.getState().undoDepth)
</script>

<template>
  <div class="toolbar">
    <button @click="engine.ext.history.undo()" :disabled="!engine.ext.history.canUndo()">
      Undo
    </button>
    <button @click="engine.ext.history.redo()" :disabled="!engine.ext.history.canRedo()">
      Redo
    </button>
    <span>{{ depth }} steps</span>
  </div>
</template>
```
