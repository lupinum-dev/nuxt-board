The history and serializer packages are intentionally separate from the core engine:

- `@lupinum/board-history` records reversible state transitions.
- `@lupinum/board-serializer` turns snapshots into JSON Canvas documents and back.

That keeps the engine lean while still supporting editor workflows that need undo, redo, import, export, and persistence.
