## CSS Custom Properties

`BoardRoot` defines theme tokens as CSS custom properties on `.board-root`. Override them to change the entire board's appearance:

```css
.board-root {
  --board-bg: #fff;
  --board-fg: #0f172a;
  --board-node-bg: #fff;
  --board-node-border: rgba(15, 23, 42, 0.15);
  --board-node-stripe: rgba(15, 23, 42, 0.07);
  --board-accent: #3b82f6;
  --board-handle-shadow: rgba(0, 0, 0, 0.2);
}
```

| Property | Default | Used for |
| --- | --- | --- |
| `--board-bg` | `#fff` | Board background. |
| `--board-fg` | `#0f172a` | Text and node borders. |
| `--board-node-bg` | `#fff` | Node background. |
| `--board-node-border` | `rgba(15, 23, 42, 0.15)` | Node border color. |
| `--board-node-stripe` | `rgba(15, 23, 42, 0.07)` | Simplified LOD node stripe pattern. |
| `--board-accent` | `#3b82f6` | Snap guides and accent elements. |
| `--board-handle-shadow` | `rgba(0, 0, 0, 0.2)` | Resize handle shadow. |

## Dark Mode

```css
.board-root.dark {
  --board-bg: #1e293b;
  --board-fg: #f1f5f9;
  --board-node-bg: #334155;
  --board-node-border: rgba(241, 245, 249, 0.15);
  --board-node-stripe: rgba(241, 245, 249, 0.07);
  --board-accent: #22d3ee;
  --board-handle-shadow: rgba(0, 0, 0, 0.4);
}
```

Or use a media query:

```css
@media (prefers-color-scheme: dark) {
  .board-root {
    --board-bg: #1e293b;
    --board-fg: #f1f5f9;
    /* ... */
  }
}
```

## Node Styling

Nodes have CSS classes you can target:

| Class | When |
| --- | --- |
| `.board-node` | Always on every node. |
| `.is-selected` | Node is selected (3px outline). |
| `.is-editing` | Node is in text editing mode. |
| `.is-locked` | Node is locked (opacity 0.7). |
| `.is-group` | Node type is `'group'` (transparent background). |
| `.board-node-simple` | Simplified LOD placeholder. |

```css
/* Custom selection style */
.board-node.is-selected {
  outline: calc(3px / var(--board-zoom, 1)) solid var(--board-accent);
  outline-offset: calc(2px / var(--board-zoom, 1));
}

/* Custom locked style */
.board-node.is-locked {
  opacity: 0.5;
  filter: grayscale(0.5);
}
```

## Grid Styling

The grid uses CSS variables set by `useGridStyle()`:

- `--grid-minor-color` — minor grid line color (auto-fades with zoom)
- `--grid-major-color` — major grid line color
- `--grid-mask-image` — edge fade mask

---

## Snap Guides

Snap guides use `--board-accent` for their color:

```css
.board-snap-guide--vertical,
.board-snap-guide--horizontal {
  background: var(--board-accent, #3b82f6);
}
```

---

## Zoom-Aware Sizing

`BoardViewport` sets `--board-zoom` to the current zoom level. Use it for zoom-independent sizing:

```css
/* Borders stay 1px regardless of zoom */
border-width: calc(1px / var(--board-zoom, 1));

/* Handle size stays constant on screen */
width: calc(12px / var(--board-zoom, 1));
```
