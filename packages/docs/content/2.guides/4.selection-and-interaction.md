## Selection

### Selecting nodes

```ts
// Replace selection with a single node
engine.select(nodeId)

// Replace with multiple nodes
engine.select([nodeA, nodeB])

// Add to existing selection
engine.select(nodeId, 'append')

// Toggle: selected nodes become deselected, and vice versa
engine.select(nodeId, 'toggle')

// Select all visible, unlocked nodes
engine.selectAll()

// Clear selection
engine.clearSelection()

// Read current selection
const selected = engine.getSelection()  // NodeId[]
```

### Selection modes

| Mode | Behavior |
| --- | --- |
| `'replace'` | Clears existing selection, selects the given IDs (default). |
| `'append'` | Adds IDs to the existing selection. |
| `'toggle'` | Flips each ID in/out of the selection. |

### Reacting to selection changes

```ts
engine.on('selection:change', (selected, prev) => {
  console.log(`Selection: ${prev.length} → ${selected.length} nodes`)
})
```

In Vue:

```vue
<script setup lang="ts">
import { useSelection } from '@lupinum/vue-board'

const selection = useSelection()
// selection.value is NodeId[]
</script>
```

## Interaction State Machine

The engine tracks pointer interactions with a discriminated union of six modes:

### Idle

```ts
{ mode: 'idle' }
```

No interaction is active. This is the default state.

### Panning

```ts
{ mode: 'panning', pointerId, lastScreenPoint }
```

Triggered by `Space + drag`, middle mouse drag, or `engine.beginPan()`. The camera moves to follow the pointer.

### Dragging nodes

```ts
{ mode: 'dragging-nodes', pointerId, nodeIds, startScreenPoint, startNodePositions }
```

Triggered by clicking and dragging a node. If the node is part of a selection, all selected nodes move. Grid snapping and edge snapping produce alignment guides.

### Resizing a node

```ts
{ mode: 'resizing-node', pointerId, nodeId, handle, startScreenPoint, startNodeBounds, aspectRatio }
```

Triggered by dragging a resize handle. The `handle` field tells you which compass direction (`'n'`, `'ne'`, `'e'`, etc.). Hold `Shift` for aspect-ratio-locked resizing.

### Box selection

```ts
{ mode: 'box-select', pointerId, startScreenPoint, currentScreenPoint, startWorldPoint, currentWorldPoint }
```

Triggered by clicking on empty canvas space and dragging. Nodes inside the box are selected on release.

### Text editing

```ts
{ mode: 'editing-text', nodeId }
```

Triggered by double-clicking a node. The built-in `BoardNode` shows a `<textarea>` in this mode.

## Driving the state machine

`BoardRoot` handles these automatically, but you can also drive them programmatically:

```ts
// Start a drag
engine.beginNodeDrag(nodeId, pointerId, screenPoint)

// Update position (call on every pointer move)
engine.updatePointer(pointerId, newScreenPoint, { shift: event.shiftKey })

// End the interaction
engine.endInteraction(pointerId)
```

For text editing:

```ts
engine.beginTextEdit(nodeId)
engine.commitTextEdit(nodeId, 'New text')
```

## Pointer Event Flow in BoardRoot

When a pointer event hits the `BoardRoot` element:

1. **Handle click** → check the target element
2. **Resize handle** → `beginResize(nodeId, handle, ...)`
3. **Node** → `beginNodeDrag(nodeId, ...)`
4. **Middle mouse / Space** → `beginPan(...)`
5. **Empty canvas** → `beginBoxSelect(...)`

On pointer move → `updatePointer()` (throttled via `requestAnimationFrame`).

On pointer up → `endInteraction()`.

---

## Multi-Touch / Pinch-to-Zoom

`BoardRoot` handles two-finger pinch gestures on touch devices. When a second pointer is detected, the board switches to pinch-to-zoom mode, adjusting the camera based on the distance between the two touch points.

## Interaction Events

```ts
engine.on('interaction:start', (state) => {
  console.log('Started:', state.mode)
})

engine.on('interaction:update', (state) => {
  // High-frequency during drag/resize
})

engine.on('interaction:end', (state) => {
  console.log('Ended:', state.mode)
})
```
