## Creating Nodes

Use `createNode()` to add a node to the board. Only `data` is required — everything else has sensible defaults:

```ts
const node = engine.createNode({
  type: 'text',
  x: 100,
  y: 200,
  data: { content: 'My card' },
})
```

### Node Input fields

| Field | Default | Description |
| --- | --- | --- |
| `id` | UUID | Auto-generated. Pass your own for deterministic scenes. |
| `type` | `'text'` | Node type key from your registry. |
| `x`, `y` | `0` | World-space position (top-left corner). |
| `width`, `height` | `240 × 160` | Node dimensions (respects `NodeConstraints`). |
| `data` | `{}` | Type-specific payload. |
| `locked` | `false` | Prevents move/resize. |
| `visible` | `true` | Hidden nodes are excluded from queries and rendering. |
| `parentId` | — | Parent group node for hierarchy. |
| `select` | `false` | Select the node immediately after creation. |

```ts
// Create and select immediately
engine.createNode({
  type: 'text',
  x: 0, y: 0,
  data: { content: 'Selected on creation' },
  select: true,
})
```

## Reading Nodes

```ts
// Get a specific node (throws if not found)
const node = engine.getNode(id)

// Safe lookup (returns null)
const maybe = engine.findNode(id)

// Check existence
if (engine.hasNode(id)) { /* ... */ }

// Find node at a world-space point (topmost visible)
const hit = engine.getNodeAt({ x: 100, y: 200 })

// Find all nodes in a region
const nodes = engine.getNodesInBounds({ minX: 0, minY: 0, maxX: 500, maxY: 500 })
```

In Vue components, use the `useNodes()` composable for reactive access:

```vue
<script setup lang="ts">
import { useNodes } from '@lupinum/vue-board'

const nodes = useNodes()
// nodes.value is ReadonlyMap<NodeId, BoardNode>
</script>
```

## Updating Nodes

`updateNode()` applies a partial patch. Only the specified fields change — the rest are preserved:

```ts
engine.updateNode(nodeId, {
  data: { content: 'Updated text' },
})

engine.updateNode(nodeId, {
  x: 300,
  y: 400,
  width: 320,
  locked: true,
})
```

The `data` field is merged at the top level — you don't need to spread the existing data.

## Moving Nodes

### moveNode

Moves a single node by a delta:

```ts
engine.moveNode(nodeId, 50, -20)  // right 50, up 20
```

### translateSelectedNodes

Moves all selected nodes by a delta. Handles group hierarchy automatically — if a group is selected, its children move too:

```ts
engine.translateSelectedNodes(10, 0)  // nudge selection right
```

This is what arrow key shortcuts use internally.

---

## Resizing Nodes

Resize a node from one of the eight compass handles:

```ts
engine.resizeNode(nodeId, 'se', 40, 30)  // expand south-east by 40×30
```

The eight handles are: `'n'`, `'ne'`, `'e'`, `'se'`, `'s'`, `'sw'`, `'w'`, `'nw'`.

Resizing respects `NodeConstraints` (minimum width/height) and grid snapping when enabled. Hold `Shift` during interactive resize for aspect-ratio locking.

## Z-Order

Nodes render in z-index order. Higher z-index values render on top.

```ts
engine.bringToFront(nodeId)  // move to highest z-index
engine.sendToBack(nodeId)    // move to lowest z-index
```

New nodes automatically get the next available z-index.

---

## Locking

Locked nodes cannot be moved, resized, or deleted through interactions. They can still be modified programmatically:

```ts
engine.lockNode(nodeId)
engine.unlockNode(nodeId)
```

Locked nodes render with reduced opacity (0.7) by default.

## Duplicating

### duplicateNodes

Duplicates specific nodes with an optional offset:

```ts
const clones = engine.duplicateNodes([nodeA, nodeB], { x: 20, y: 20 })
```

### Clipboard

Copy/paste uses an internal clipboard:

```ts
engine.copySelected()              // copy selection to clipboard
engine.pasteClipboard({ x: 20, y: 20 })  // paste with offset
```

The clipboard is internal to the engine — it does not use the system clipboard.

---

## Deleting Nodes

```ts
// Delete a specific node
engine.deleteNode(nodeId)

// Delete all selected nodes
engine.deleteSelected()
```

Deleting a group node also deletes all its descendants. If the connections plugin is installed, edges connected to deleted nodes are removed automatically.

## Seeding with Initial Nodes

For SSR or deterministic scenes, pass `initialNodes` to the engine:

```ts
import { asNodeId } from '@lupinum/board-core'

const engine = createBoardEngine({
  initialNodes: [
    {
      id: asNodeId('node-1'),
      type: 'text',
      x: 0, y: 0,
      width: 240, height: 160,
      data: { content: 'Seeded node' },
      zIndex: 1,
      locked: false,
      visible: true,
    },
  ],
})
```

## Events

Listen for node lifecycle events:

```ts
engine.on('node:created', (node) => console.log('Created:', node.id))
engine.on('node:updated', (node, prev) => console.log('Updated:', node.id))
engine.on('node:deleted', (id, prev) => console.log('Deleted:', id))
engine.on('node:moved', (node, delta) => console.log('Moved:', delta))
engine.on('node:resized', (node, prev) => console.log('Resized:', node.id))
```
