## How Middleware Works

Middleware functions intercept every engine command before it executes. Call `next()` to allow the command, or omit it to block:

```ts
const unsub = engine.addMiddleware((name, args, next) => {
  console.log('Command:', name)
  next()  // allow the command
})
```

---

## Blocking Commands

Omit `next()` to silently cancel a command. The engine emits a `command:blocked` event:

```ts
engine.addMiddleware((name, args, next) => {
  if (name === 'deleteNode' || name === 'deleteSelected') {
    return  // block all deletes
  }
  next()
})

engine.on('command:blocked', (name) => {
  console.log('Blocked:', name)
})
```

---

## Read-Only Mode

Block all mutation commands to create a view-only board:

```ts
const readOnlyCommands = new Set([
  'createNode', 'updateNode', 'deleteNode', 'moveNode',
  'resizeNode', 'deleteSelected', 'duplicateNodes',
  'translateSelectedNodes', 'bringToFront', 'sendToBack',
  'lockNode', 'unlockNode', 'commitTextEdit',
])

engine.addMiddleware((name, args, next) => {
  if (readOnlyCommands.has(name)) return
  next()
})
```

---

## Logging

```ts
engine.addMiddleware((name, args, next) => {
  const start = performance.now()
  next()
  console.log(`${name}: ${(performance.now() - start).toFixed(1)}ms`)
})
```

---

## Stacking Middlewares

Multiple middlewares execute in registration order. Each must call `next()` to pass to the next middleware, then to the command:

```ts
engine.addMiddleware((name, args, next) => {
  console.log('Middleware 1: before')
  next()
  console.log('Middleware 1: after')
})

engine.addMiddleware((name, args, next) => {
  console.log('Middleware 2: before')
  next()
})
// Output: "1: before" → "2: before" → command executes → "1: after"
```

---

## Removing Middleware

`addMiddleware()` returns an unsubscribe function:

```ts
const unsub = engine.addMiddleware((name, args, next) => next())

// Later:
unsub()
```
