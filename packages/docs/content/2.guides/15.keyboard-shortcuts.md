## Shortcut Reference

`BoardRoot` handles these keyboard shortcuts automatically. All shortcuts work when the board root element has focus.

### Selection

| Key | Action |
| --- | --- |
| `Ctrl/Cmd + A` | Select all visible, unlocked nodes. |
| `Escape` | Clear selection and end interaction. |

### Editing

| Key | Action |
| --- | --- |
| `Enter` | Begin text editing on the selected node (single selection). |
| `Double-click node` | Begin text editing. |
| `Double-click empty area` | Create a new text node and begin editing. |

### Clipboard

| Key | Action |
| --- | --- |
| `Ctrl/Cmd + C` | Copy selected nodes to internal clipboard. |
| `Ctrl/Cmd + V` | Paste from internal clipboard. |
| `Ctrl/Cmd + D` | Duplicate selected nodes. |

### Delete

| Key | Action |
| --- | --- |
| `Delete` | Delete selected nodes. |
| `Backspace` | Delete selected nodes. |

### Navigation

| Key | Action |
| --- | --- |
| `Arrow keys` | Nudge selected nodes by one grid step. |
| `Shift + Arrow keys` | Nudge by one major grid step. |
| `Ctrl/Cmd + 0` | Zoom to 100%. |
| `Ctrl/Cmd + 1` | Zoom to fit all nodes. |
| `Space + drag` | Pan the canvas. |
| `Middle mouse drag` | Pan the canvas. |
| `Scroll wheel` | Pan the canvas. |
| `Ctrl/Cmd + scroll` | Zoom at cursor. |
| `Pinch gesture` | Zoom in/out (touch devices). |

### History (requires history plugin)

| Key | Action |
| --- | --- |
| `Ctrl/Cmd + Z` | Undo. |
| `Ctrl/Cmd + Shift + Z` | Redo. |
| `Ctrl/Cmd + Y` | Redo. |

---

## Editor Pass-Through

When a `<textarea>` or `contenteditable` element is focused (text editing mode), keyboard shortcuts are suppressed so you can type normally. The `data-editor="true"` attribute marks elements as editor targets.

The `Space` key is also suppressed during text editing — it only triggers pan mode when no editor is active.
