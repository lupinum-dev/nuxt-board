## Grid Configuration

Set grid options during engine creation:

```ts
const engine = createBoardEngine({
  grid: {
    size: 20,          // cell size in world units
    majorEvery: 5,     // major grid line every 5 cells
    snap: true,        // snap nodes to grid
    pattern: 'line',   // visual pattern
  },
})
```

### Update at runtime

```ts
engine.updateGridSettings({ size: 24, pattern: 'cross' })
```

---

## Grid Patterns

| Pattern | Description |
| --- | --- |
| `'line'` | Horizontal and vertical lines (default). |
| `'dot'` | Dots at grid intersections. |
| `'cross'` | Small crosshairs at intersections. |
| `'none'` | No visual grid. |

---

## Visual Options

Control grid appearance through `BoardRoot`'s `grid` prop:

```vue
<BoardRoot
  :engine="engine"
  :grid="{
    visible: true,
    minorOpacity: 0.14,
    majorOpacity: 0.18,
    fadeEdges: true,
  }"
/>
```

| Option | Default | Description |
| --- | --- | --- |
| `visible` | `true` | Show/hide the grid. |
| `minorOpacity` | `0.14` | Opacity of minor grid lines. |
| `majorOpacity` | `0.18` | Opacity of major grid lines. |
| `fadeEdges` | `true` | Fade the grid at viewport edges (radial gradient mask). |

Grid opacity automatically reduces at low zoom levels — minor lines fade below 12px screen size and disappear below 6px.

---

## Snap Behavior

When `snap: true`, these operations snap to the grid:

- **Creating nodes** — position snaps to grid
- **Moving nodes** — position snaps to grid
- **Resizing nodes** — edges snap to grid
- **Arrow key nudge** — moves by one grid step (Shift for major step)

### Edge snapping

During drag and resize, the engine also checks alignment with nearby node edges. When a node edge aligns with another node, a snap guide line appears. This works independently of grid snapping.

## Grid Style in Custom Components

Use `useGridStyle()` to get the computed CSS variables for custom grid rendering:

```vue
<script setup lang="ts">
import { useGridStyle } from '@lupinum/vue-board'

const gridStyle = useGridStyle()
// gridStyle.value contains:
// --grid-minor-size, --grid-major-size, --grid-minor-color, --grid-major-color, etc.
</script>
```
