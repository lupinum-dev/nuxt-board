This recipe creates a read-only board viewer by using middleware to block all mutation commands.

## Approach

Use `addMiddleware()` to intercept and block mutation commands. Camera navigation (pan, zoom) still works so users can explore the board.

## Implementation

```ts
const engine = createBoardEngine()

// Load board data
engine.importJSON(savedBoardJson, 'replace')

// Block all mutations
const mutationCommands = new Set([
  'createNode', 'updateNode', 'deleteNode',
  'moveNode', 'resizeNode', 'deleteSelected',
  'duplicateNodes', 'translateSelectedNodes',
  'bringToFront', 'sendToBack',
  'lockNode', 'unlockNode',
  'commitTextEdit', 'copySelected', 'pasteClipboard',
])

engine.addMiddleware((name, args, next) => {
  if (mutationCommands.has(name)) return  // block
  next()  // allow camera, selection, interaction commands
})
```

## Optional: Disable Visual Interactions

You may also want to prevent drag/resize handles from appearing and double-click from triggering edit mode. Add CSS to suppress pointer events on nodes:

```css
.board-root.read-only .board-node {
  pointer-events: none;
}
```

Or block interaction commands too:

```ts
const blockedInteractions = new Set([
  'beginNodeDrag', 'beginResize', 'beginTextEdit',
  'beginBoxSelect',
])

engine.addMiddleware((name, args, next) => {
  if (mutationCommands.has(name)) return
  if (blockedInteractions.has(name)) return
  next()
})
```

## Template

```vue
<BoardRoot
  :engine="engine"
  class="read-only h-screen"
  :grid="{ visible: true }"
/>
```

## Toggling Read-Only Mode

Use the unsubscribe function to toggle:

```ts
let unsub: (() => void) | null = null

function setReadOnly(enabled: boolean) {
  if (enabled && !unsub) {
    unsub = engine.addMiddleware((name, args, next) => {
      if (mutationCommands.has(name)) return
      next()
    })
  } else if (!enabled && unsub) {
    unsub()
    unsub = null
  }
}
```

---

## Key Patterns Used

- **Middleware** — blocks commands before they execute
- **Selective blocking** — mutations blocked, navigation allowed
- **Toggleable** — unsubscribe function enables switching modes
