This recipe uses group nodes as kanban columns and regular nodes as cards. When a card is dragged into a different column, it reparents automatically.

## Engine Setup

```ts
type KanbanRegistry = {
  column: { title: string; color: string }
  card: { title: string; assignee?: string }
}

const engine = createBoardEngine<KanbanRegistry>({
  grid: { size: 16, snap: true },
  plugins: [historyPlugin()],
})
```

## Creating Columns

```ts
const todo = engine.createNode({
  type: 'column', x: 0, y: 0,
  width: 280, height: 600,
  data: { title: 'To Do', color: '#94a3b8' },
})

const inProgress = engine.createNode({
  type: 'column', x: 320, y: 0,
  width: 280, height: 600,
  data: { title: 'In Progress', color: '#3b82f6' },
})

const done = engine.createNode({
  type: 'column', x: 640, y: 0,
  width: 280, height: 600,
  data: { title: 'Done', color: '#22c55e' },
})

// Send columns to back so cards render on top
engine.sendToBack(todo.id)
engine.sendToBack(inProgress.id)
engine.sendToBack(done.id)
```

## Creating Cards

```ts
engine.createNode({
  type: 'card', x: 16, y: 60,
  width: 248, height: 80,
  data: { title: 'Design login page', assignee: 'Alice' },
  parentId: todo.id,
})
```

## Auto-Reparenting After Drag

Listen for `node:moved` and check which column the card landed in:

```ts
import { findContainingGroup } from '@lupinum/board-core'

engine.on('node:moved', (node) => {
  if (node.type !== 'card') return

  const state = engine.getState()
  const newParent = findContainingGroup(node, state.nodes)

  if (newParent && newParent !== node.parentId) {
    engine.updateNode(node.id, { parentId: newParent })
  }
})
```

## Key Patterns Used

- **Groups as containers** — columns are group nodes, cards have `parentId`
- **Auto-reparenting** — `findContainingGroup()` detects which column a card lands in
- **Z-order management** — columns sent to back so cards render on top
- **Custom renderers** — separate visual treatment for columns vs cards
