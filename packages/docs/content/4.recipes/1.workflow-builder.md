This recipe shows how to combine custom renderers, the connections plugin, and serialization to build a workflow/pipeline editor.

## Engine Setup

```ts
import { createBoardEngine } from '@lupinum/board-core'
import { historyPlugin } from '@lupinum/board-history'
import { connectionPlugin } from '@lupinum/board-connections'

const engine = createBoardEngine<{
  step: { label: string; status: 'pending' | 'active' | 'done' }
}>({
  grid: { size: 24, snap: true },
  plugins: [
    historyPlugin(),
    connectionPlugin({ routing: 'step' }),
  ],
})
```

## Building the Pipeline

```ts
const input = engine.createNode({
  type: 'step', x: 0, y: 100,
  width: 180, height: 80,
  data: { label: 'Receive Data', status: 'done' },
})

const process = engine.createNode({
  type: 'step', x: 280, y: 100,
  width: 180, height: 80,
  data: { label: 'Transform', status: 'active' },
})

const output = engine.createNode({
  type: 'step', x: 560, y: 100,
  width: 180, height: 80,
  data: { label: 'Write Output', status: 'pending' },
})

engine.ext.connections.createEdge({
  from: input.id, to: process.id,
  fromAnchor: { side: 'right', offset: 0.5 },
  toAnchor: { side: 'left', offset: 0.5 },
  data: {},
})

engine.ext.connections.createEdge({
  from: process.id, to: output.id,
  fromAnchor: { side: 'right', offset: 0.5 },
  toAnchor: { side: 'left', offset: 0.5 },
  data: {},
})
```

## Updating Step Status

```ts
function markStepDone(nodeId: NodeId) {
  const node = engine.getNode(nodeId)
  engine.updateNode(nodeId, {
    data: { ...node.data, status: 'done' },
  })
}
```

## Persistence

```ts
import { jsonCanvasSerializer } from '@lupinum/board-serializer'

// Save
function save() {
  const edges = engine.ext.connections.getEdges()
  const json = jsonCanvasSerializer.export(engine, { edges })
  localStorage.setItem('workflow', json)
}

// Load
function load() {
  const stored = localStorage.getItem('workflow')
  if (!stored) return
  const doc = jsonCanvasSerializer.parse(stored)
  const snapshot = jsonCanvasSerializer.toSnapshot(doc)
  engine.importJSON(JSON.stringify(snapshot), 'replace')
}
```

## Key Patterns Used

- **Type-safe registry** — the `step` type enforces `{ label, status }` data
- **Custom renderer** — visual status indicators per node type
- **Stepped routing** — right-angle connections for workflow aesthetics
- **Anchored edges** — connections attach at specific sides
- **Serialization with edges** — persist the full graph
