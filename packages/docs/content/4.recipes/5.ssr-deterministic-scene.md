This recipe shows how to create a board with a known initial state for SSR-compatible rendering.

## The Problem

In SSR contexts, the board engine runs on the server where there's no DOM. You need a deterministic scene that renders the same HTML on server and client.

## Using initialNodes

Pass pre-defined nodes at engine creation — no random IDs, no `createNode()` calls:

```ts
import { createBoardEngine, asNodeId } from '@lupinum/board-core'

const engine = createBoardEngine({
  camera: { x: 0, y: 0, z: 1 },
  grid: { size: 20, snap: true },
  initialNodes: [
    {
      id: asNodeId('welcome'),
      type: 'text',
      x: 100, y: 100,
      width: 280, height: 120,
      data: { content: 'Welcome to the board' },
      zIndex: 1,
      locked: false,
      visible: true,
    },
    {
      id: asNodeId('getting-started'),
      type: 'text',
      x: 440, y: 100,
      width: 280, height: 120,
      data: { content: 'Drag, resize, and explore' },
      zIndex: 2,
      locked: false,
      visible: true,
    },
  ],
})
```

### Key points

- Use `asNodeId('...')` with deterministic string IDs — not `crypto.randomUUID()`
- Include all required fields: `id`, `type`, `x`, `y`, `width`, `height`, `data`, `zIndex`, `locked`, `visible`
- Set `camera` to a fixed position

## Using importJSON

For more complex scenes, use snapshot import:

```ts
function createDemoSnapshot() {
  return {
    camera: { x: -20, y: -20, z: 0.9 },
    grid: { size: 24, majorEvery: 4, snap: true, pattern: 'line' },
    nodes: [
      { id: 'step-1', type: 'text', x: 0, y: 0, width: 240, height: 120,
        data: { content: 'Step 1' }, zIndex: 1, locked: false, visible: true },
      { id: 'step-2', type: 'text', x: 300, y: 0, width: 240, height: 120,
        data: { content: 'Step 2' }, zIndex: 2, locked: false, visible: true },
    ],
    selection: [],
    interaction: { mode: 'idle' },
    snapGuides: [],
    nextZIndex: 3,
  }
}

const engine = createBoardEngine()
engine.importJSON(JSON.stringify(createDemoSnapshot()), 'replace')
```

## Nuxt / SSR Template

```vue
<script setup lang="ts">
const engine = createBoardEngine({
  initialNodes: getInitialNodes(),
})

onMounted(async () => {
  await engine.zoomToFit(40, false)
})
</script>

<template>
  <BoardRoot :engine="engine" class="h-[600px]" />
</template>
```

The `onMounted` hook fires only on the client, so animated zoom-to-fit happens after hydration.

---

## Key Patterns Used

- **initialNodes** — deterministic seed data at engine creation
- **Branded IDs** — `asNodeId()` for explicit, reproducible node IDs
- **Snapshot import** — full scene state including camera and grid
- **Client-only animation** — `onMounted` for post-hydration zoom
