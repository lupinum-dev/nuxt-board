This example shows a minimal board with node creation, selection, grouping, and zoom-to-fit — the core features you get out of the box.

::basic-board-demo
::

## How It Works

### Engine setup

The board uses `createBoardEngine` with a 20px grid:

```ts
const engine = createBoardEngine({
  grid: { size: 20, majorEvery: 5, snap: true, pattern: 'line' },
})
```

### Seeding the scene

Three nodes are loaded via `importJSON` with a pre-configured camera position:

```ts
engine.importJSON(JSON.stringify({
  camera: { x: -80, y: -20, z: 1 },
  grid: engine.getGridSettings(),
  nodes: [
    { id: 'brief', type: 'text', x: 80, y: 80, width: 220, height: 120,
      data: { content: 'Brief\nMap the core flows' }, zIndex: 1, locked: false, visible: true },
    { id: 'draft', type: 'text', x: 360, y: 220, width: 240, height: 140,
      data: { content: 'Draft\nSketch the happy path' }, zIndex: 2, locked: false, visible: true },
    { id: 'review', type: 'text', x: 650, y: 100, width: 220, height: 120,
      data: { content: 'Review\nRefine details with the team' }, zIndex: 3, locked: false, visible: true },
  ],
  selection: [],
  interaction: { mode: 'idle' },
  snapGuides: [],
  nextZIndex: 4,
}), 'replace')
```

### Adding nodes dynamically

The "Add note" button creates a node at a random position:

```ts
engine.createNode({
  type: 'text',
  x: 180 + Math.round(Math.random() * 320),
  y: 140 + Math.round(Math.random() * 160),
  width: 220, height: 120,
  data: { content: 'Note\nCreated from the docs demo' },
})
```

### Wrapping selection in a group

The "Wrap selection" button calculates the bounding box of selected nodes, creates a group node around them with padding, and reparents the nodes:

```ts
const group = engine.createNode({
  type: 'group',
  x: minX - 28, y: minY - 28,
  width: maxX - minX + 56, height: maxY - minY + 56,
  data: { title: 'Cluster' },
})
engine.sendToBack(group.id)
for (const node of selected) {
  engine.updateNode(node.id, { parentId: group.id })
}
engine.syncGroupZOrder(group.id)
```

## Try It

- **Select multiple nodes** by clicking them while holding Shift, or drag an empty area to box-select.
- **Wrap them** with the "Wrap selection" button to create a group.
- **Double-click** empty space to create a new node, or double-click an existing node to edit its text.
- **Drag nodes** to reposition them — notice the grid snapping.
- **Scroll** to pan, **Ctrl/Cmd + scroll** to zoom.
