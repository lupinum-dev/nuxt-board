This example mixes the built-in text renderer with a custom "insight" card renderer.

::renderer-board-demo
::

## How It Works

### Defining a custom renderer

A renderer is a Vue component that receives `node`, `selected`, and `editing` props:

```vue
<script setup lang="ts">
import type { BoardNode } from '@lupinum/board-core'

defineProps<{
  node: BoardNode
  selected: boolean
}>()
</script>

<template>
  <div class="insight-card" :class="{ 'ring-2 ring-teal-400': selected }">
    <span class="label">{{ node.data.label }}</span>
    <h3>{{ node.data.title }}</h3>
    <p>{{ node.data.body }}</p>
  </div>
</template>
```

### Registering renderers

Pass a `renderers` map to `BoardRoot`:

```ts
import DocsInsightNode from './DocsInsightNode.vue'

const renderers = { insight: DocsInsightNode }
```

```vue
<BoardRoot :engine="engine" :renderers="renderers" />
```

### Mixing node types

The board renders custom and default nodes side by side. Types not in the registry fall back to the built-in text renderer:

```ts
engine.createNode({ type: 'insight', x: 60, y: 60,
  data: { label: 'FINDING', title: 'Custom card', body: 'With teal gradient' } })

engine.createNode({ type: 'text', x: 400, y: 120,
  data: { content: 'Standard text card' } })
```

## Try It

- **Compare** the custom teal card with the standard text card.
- **Add more** insight cards — they all use the same renderer.
- **Drag and resize** both types — interactions work the same regardless of renderer.
