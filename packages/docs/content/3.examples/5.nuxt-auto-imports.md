## How It Works

### Module setup

Add `@lupinum/nuxt-board` to your Nuxt config:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-board'],
})
```

### No imports needed

`createBoardEngine`, `BoardRoot`, and all composables are available globally:

```vue
<script setup lang="ts">
// No imports! Everything is auto-imported
const engine = createBoardEngine({
  grid: { size: 20, snap: true },
})

engine.createNode({
  type: 'text', x: 100, y: 100,
  data: { content: 'Auto-imported!' },
})
</script>

<template>
  <BoardRoot :engine="engine" class="h-screen" />
</template>
```

### What gets auto-imported

| Category | Items |
| --- | --- |
| **Components** | `BoardRoot`, `BoardViewport`, `BoardNode`, `BoardNodeHandle`, `BoardGrid`, `BoardBoxSelect`, `BoardSnapGuides` |
| **Composables** | `useBoardEngine`, `useCamera`, `useNodes`, `useSelection`, `useInteraction`, `useVisibleBounds`, `useVisibleNodes`, `useGridStyle`, `useNode`, `useBoxSelectBounds` |
| **Functions** | `createBoardEngine` |

## Try It
