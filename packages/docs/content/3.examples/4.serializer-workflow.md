This example demonstrates a round-trip serialization workflow — export the board to JSON Canvas format, edit the JSON, and import it back.

::serializer-board-demo
::

## How It Works

### Exporting

The serializer converts the engine state to a JSON Canvas string:

```ts
import { jsonCanvasSerializer } from '@lupinum/board-serializer'

const json = jsonCanvasSerializer.export(engine)
```

With edges:

```ts
const edges = engine.ext.connections.getEdges()
const json = jsonCanvasSerializer.export(engine, { edges })
```

### Importing

Parse the JSON and convert to a snapshot:

```ts
const document = jsonCanvasSerializer.parse(jsonString)
const snapshot = jsonCanvasSerializer.toSnapshot(document)
engine.importJSON(JSON.stringify(snapshot), 'replace')
```

### JSON Canvas format

The output follows the [JSON Canvas spec](https://jsoncanvas.org/) with board extensions in `x-canvas`:

```json
{
  "nodes": [
    { "id": "n1", "type": "text", "x": 100, "y": 100, "width": 240, "height": 160, "text": "Hello" }
  ],
  "x-canvas": {
    "camera": { "x": 0, "y": 0, "z": 1 },
    "grid": { "size": 20, "majorEvery": 5, "snap": true, "pattern": "line" }
  }
}
```

## Try It

- **Export** the board and inspect the JSON in the textarea.
- **Edit the JSON** directly — change positions, text, or add nodes.
- **Import** to apply your changes.
