This example shows a pipeline-style board with edges connecting nodes, an undo/redo history, and a minimap for navigation.

::connections-board-demo
::

## How It Works

### Plugin setup

The engine uses both the history and connections plugins:

```ts
import { historyPlugin } from '@lupinum/board-history'
import { connectionPlugin } from '@lupinum/board-connections'

const engine = createBoardEngine({
  grid: { size: 24, majorEvery: 4, snap: true, pattern: 'line' },
  plugins: [historyPlugin(), connectionPlugin()],
})
```

### Creating edges

Edges connect nodes by ID:

```ts
engine.ext.connections.createEdge({
  from: inputNodeId,
  to: parseNodeId,
  data: { label: 'clean' },
})
```

### Rendering the connection layer

`BoardConnectionLayer` renders edges as SVG paths inside the viewport:

```vue
<BoardRoot :engine="engine">
  <template #viewport>
    <BoardConnectionLayer />
  </template>
  <template #default>
    <BoardMinimap :width="180" :height="110" />
  </template>
</BoardRoot>
```

### Undo/redo

The history plugin captures every node and edge change. Toolbar buttons check `canUndo()`/`canRedo()`:

```ts
engine.ext.history.undo()
engine.ext.history.redo()
engine.ext.history.getState().undoDepth
```

## Try It

- **Drag nodes** to rearrange the pipeline — edges follow automatically.
- **Undo/redo** changes with the toolbar buttons or `Ctrl/Cmd + Z`.
- **Watch the minimap** update as you pan and zoom.
- **Click the minimap** to navigate to a different area.
