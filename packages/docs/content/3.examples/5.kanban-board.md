## What’s happening

The columns are just group nodes. The cards are normal nodes with `parentId` pointing at the containing column. When you drag a card and its center enters another group, the board reparents it.

## The code

::code-tree{defaultValue="app.vue"}

```ts [app.vue]
import { createBoardEngine, findContainingGroup } from '@lupinum/board-core'

engine.on('node:moved', (node) => {
  if (node.type !== 'text') return

  const nextParent = findContainingGroup(node, engine.getState().nodes)
  if (nextParent !== node.parentId) {
    engine.updateNode(node.id, { parentId: nextParent })
  }
})
```

```ts [seed.ts]
engine.createNode({ type: 'group', data: { title: 'To Do' } })
engine.createNode({ type: 'text', parentId: todo.id, data: { content: 'Draft onboarding copy' } })
```
