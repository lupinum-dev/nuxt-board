## What’s happening

This example combines three patterns: a custom renderer for step cards, the connections plugin for flow lines, and the history plugin for undo and redo. It feels like a product because the docs are using the same engine and renderer boundary you would use in an app.

## The code

::code-tree{defaultValue="app.vue"}

```vue [app.vue]
<script setup lang="ts">
import { createBoardEngine } from '@lupinum/board-core'
import { historyPlugin } from '@lupinum/board-history'
import { connectionPlugin, BoardConnectionLayer } from '@lupinum/board-connections'
import StepNode from './StepNode.vue'

const engine = createBoardEngine({
  plugins: [historyPlugin(), connectionPlugin({ routing: 'step' })]
})
</script>

<template>
  <BoardRoot :engine="engine" :renderers="{ step: StepNode }">
    <BoardConnectionLayer routing="step" />
  </BoardRoot>
</template>
```

```vue [StepNode.vue]
<template>
  <div class="step-card">
    <span>{{ node.data.status }}</span>
    <strong>{{ node.data.label }}</strong>
  </div>
</template>
```

::

## Try these things

- Select a step, then click `Cycle selected step`.
- Drag a step and watch the routed edges stay readable.
- Undo and redo a few changes to confirm the board behavior stays coherent.
