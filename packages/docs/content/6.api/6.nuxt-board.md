## Install

::code-group

```bash [pnpm]
pnpm add nuxt-board
```

```bash [npm]
npm install nuxt-board
```

::

Add the module to `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-board'],
  board: {
    // options
  },
})
```

---

## Module Options

Configure via the `board` key in `nuxt.config.ts`:

| Name                    | Type      | Default | Description                                                                                                                            |
| ----------------------- | --------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `prefix`                | `string`  | `''`    | Optional prefix for all auto-imported exports. Example: `'My'` produces `<MyBoardRoot>`, `useMyCamera()`, and `createMyBoardEngine()`. |
| `autoImportComponents`  | `boolean` | `true`  | Auto-import board components globally.                                                                                                 |
| `autoImportComposables` | `boolean` | `true`  | Auto-import board composables globally.                                                                                                |

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-board'],
  board: {
    prefix: 'My',
    autoImportComponents: true,
    autoImportComposables: true,
  },
})
```

## Auto-Imported Components

When `autoImportComponents` is `true` (default), these components are available globally without imports:

| Component               | Source               |
| ----------------------- | -------------------- |
| `BoardRoot`             | `@lupinum/vue-board` |
| `BoardViewport`         | `@lupinum/vue-board` |
| `BoardNode`             | `@lupinum/vue-board` |
| `BoardNodeHandle`       | `@lupinum/vue-board` |
| `BoardSelectionToolbar` | `@lupinum/vue-board` |
| `BoardGrid`             | `@lupinum/vue-board` |
| `BoardBoxSelect`        | `@lupinum/vue-board` |
| `BoardSnapGuides`       | `@lupinum/vue-board` |

With a prefix of `'My'`, they become `<MyBoardRoot>`, `<MyBoardViewport>`, etc.

---

## Auto-Imported Composables

When `autoImportComposables` is `true` (default), these are available without imports:

| Composable           | Source               |
| -------------------- | -------------------- |
| `useBoardEngine`     | `@lupinum/vue-board` |
| `useCamera`          | `@lupinum/vue-board` |
| `useNodes`           | `@lupinum/vue-board` |
| `useSelection`       | `@lupinum/vue-board` |
| `useInteraction`     | `@lupinum/vue-board` |
| `useVisibleBounds`   | `@lupinum/vue-board` |
| `useVisibleNodes`    | `@lupinum/vue-board` |
| `useGridStyle`       | `@lupinum/vue-board` |
| `useNode`            | `@lupinum/vue-board` |
| `useBoxSelectBounds` | `@lupinum/vue-board` |

With a prefix of `'My'`, these aliases become `useMyBoardEngine()`, `useMyCamera()`, `useMyNodes()`, and so on.

## Auto-Imported Functions

| Function            | Source                |
| ------------------- | --------------------- |
| `createBoardEngine` | `@lupinum/board-core` |

With a prefix of `'My'`, the helper becomes `createMyBoardEngine()`.

## Usage

With the Nuxt module installed, you can use board features without any imports:

```vue [app.vue]
<script setup lang="ts">
const engine = createBoardEngine({
  grid: { size: 20, snap: true },
})

engine.createNode({
  type: 'text',
  x: 100,
  y: 100,
  data: { content: 'Hello from Nuxt!' },
})
</script>

<template>
  <BoardRoot :engine="engine" class="h-screen" />
</template>
```
