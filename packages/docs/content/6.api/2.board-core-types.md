This page documents every type and interface exported by `@lupinum/board-core`.

## Branded IDs

### NodeId

Branded string type for node identifiers. Use `asNodeId()` to cast a plain string.

```ts
type NodeId = string & { readonly __brand: 'NodeId' }
```

```ts
import { asNodeId } from '@lupinum/board-core'
const id = asNodeId('my-node-1')
```

### EdgeId

Branded string type for edge identifiers. Use `asEdgeId()` to cast a plain string.

```ts
type EdgeId = string & { readonly __brand: 'EdgeId' }
```

## Geometry

### Point

A 2D coordinate.

```ts
interface Point {
  x: number
  y: number
}
```

### Bounds

An axis-aligned bounding box.

```ts
interface Bounds {
  minX: number
  minY: number
  maxX: number
  maxY: number
}
```

### Camera

Camera position and zoom. `x` and `y` are the world-space offset, `z` is the zoom level (1 = 100%).

```ts
interface Camera {
  x: number
  y: number
  z: number  // zoom level
}
```

### ZoomSettings

Constraints for the zoom range.

```ts
interface ZoomSettings {
  min: number  // default: 0.1
  max: number  // default: 8
}
```

## Grid

### GridPattern

Available grid visual patterns.

```ts
type GridPattern = 'dot' | 'line' | 'cross' | 'none'
```

### GridSettings

Grid configuration for snapping and visual rendering.

```ts
interface GridSettings {
  size: number        // grid cell size in world units (default: 10)
  majorEvery: number  // major grid line every N cells (default: 5)
  snap: boolean       // whether node operations snap to grid (default: true)
  pattern: GridPattern // visual pattern (default: 'line')
}
```

## Nodes

### NodeData

Base type for node payloads.

```ts
type NodeData = Record<string, unknown>
```

### NodeTypeRegistry

Maps node type strings to their data shapes. Used as the generic parameter for type-safe node operations.

```ts
type NodeTypeRegistry = Record<string, NodeData>
```

```ts
// Example: define your own registry
type MyRegistry = {
  text: { content: string }
  image: { src: string; alt: string }
  group: { title: string; accent: string }
}
```

### BoardNode

The immutable node record. Every field is `readonly`.

```ts
interface BoardNode<TType extends string = string, TData extends NodeData = NodeData> {
  readonly id: NodeId
  readonly type: TType           // node type key from your registry
  readonly x: number             // world-space X position
  readonly y: number             // world-space Y position
  readonly width: number         // width in world units
  readonly height: number        // height in world units
  readonly data: TData           // type-safe payload
  readonly zIndex: number        // rendering order (higher = on top)
  readonly locked: boolean       // prevents move/resize when true
  readonly visible: boolean      // hidden nodes are excluded from queries
  readonly parentId?: NodeId     // parent group node (hierarchy)
}
```

### ResolvedNode

Type-safe specialization of `BoardNode` for a specific registry and type key.

```ts
type ResolvedNode<R extends NodeTypeRegistry, T extends keyof R = keyof R> =
  T extends keyof R ? BoardNode<T & string, R[T]> : never
```

### NodeInput

Partial input for creating a node. All fields except `data` have defaults.

```ts
interface NodeInput<R extends NodeTypeRegistry, T extends keyof R = keyof R> {
  id?: NodeId           // auto-generated UUID if omitted
  type?: T & string     // defaults to 'text'
  x?: number            // defaults to 0
  y?: number            // defaults to 0
  width?: number        // defaults to NodeConstraints.defaultWidth
  height?: number       // defaults to NodeConstraints.defaultHeight
  data?: R[T]           // type-safe payload
  locked?: boolean      // defaults to false
  visible?: boolean     // defaults to true
  parentId?: NodeId     // optional parent group
  select?: boolean      // select after creation (defaults to false)
}
```

### NodePatch

Partial update for an existing node. Only the specified fields are changed.

```ts
type NodePatch<R extends NodeTypeRegistry, T extends keyof R = keyof R> =
  Partial<Pick<ResolvedNode<R, T>, 'x' | 'y' | 'width' | 'height' | 'data' | 'locked' | 'visible' | 'parentId'>>
```

### NodeConstraints

Dimensional constraints applied to all nodes.

```ts
interface NodeConstraints {
  minWidth: number       // default: 50
  minHeight: number      // default: 50
  defaultWidth: number   // default: 240
  defaultHeight: number  // default: 160
}
```

### ResizeHandle

The eight compass directions for resize handles.

```ts
type ResizeHandle = 'n' | 'ne' | 'e' | 'se' | 's' | 'sw' | 'w' | 'nw'
```

## Selection

### SelectionMode

Controls how `select()` modifies the selection.

```ts
type SelectionMode = 'replace' | 'append' | 'toggle'
```

| Value | Behavior |
| --- | --- |
| `'replace'` | Clears the existing selection and selects the given IDs. |
| `'append'` | Adds the given IDs to the existing selection. |
| `'toggle'` | Toggles each ID — selected nodes become deselected and vice versa. |

## Interaction State

The interaction system is a discriminated union state machine. The `mode` field determines which interaction is active.

### InteractionMode

```ts
type InteractionMode =
  | 'idle'
  | 'panning'
  | 'dragging-nodes'
  | 'resizing-node'
  | 'box-select'
  | 'editing-text'
```

### InteractionState

```ts
type InteractionState =
  | IdleInteractionState
  | PanInteractionState
  | DragInteractionState
  | ResizeInteractionState
  | BoxSelectInteractionState
  | EditingInteractionState
```

### IdleInteractionState

No interaction is active.

```ts
interface IdleInteractionState {
  mode: 'idle'
}
```

### PanInteractionState

The user is panning the canvas.

```ts
interface PanInteractionState {
  mode: 'panning'
  pointerId: number       // pointer that initiated the pan
  lastScreenPoint: Point  // last screen-space pointer position
}
```

### DragInteractionState

One or more nodes are being dragged.

```ts
interface DragInteractionState {
  mode: 'dragging-nodes'
  pointerId: number
  nodeIds: NodeId[]                          // nodes being dragged
  startScreenPoint: Point                    // screen point at drag start
  startNodePositions: Record<NodeId, Point>  // original positions
}
```

### ResizeInteractionState

A node is being resized from a handle.

```ts
interface ResizeInteractionState {
  mode: 'resizing-node'
  pointerId: number
  nodeId: NodeId                                           // node being resized
  handle: ResizeHandle                                     // which handle is active
  startScreenPoint: Point                                  // screen point at resize start
  startNodeBounds: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>  // original bounds
  aspectRatio: number                                      // width / height at start
}
```

### BoxSelectInteractionState

A box selection is in progress.

```ts
interface BoxSelectInteractionState {
  mode: 'box-select'
  pointerId: number
  startScreenPoint: Point    // screen point at box start
  currentScreenPoint: Point  // current screen pointer
  startWorldPoint: Point     // world-space start
  currentWorldPoint: Point   // world-space current
}
```

### EditingInteractionState

A node is in text editing mode.

```ts
interface EditingInteractionState {
  mode: 'editing-text'
  nodeId: NodeId  // node being edited
}
```

## Board State

### BoardState

The full runtime state of the board.

```ts
interface BoardState<R extends NodeTypeRegistry = NodeTypeRegistry> {
  readonly camera: Camera
  readonly nodes: ReadonlyMap<NodeId, ResolvedNode<R>>
  readonly selection: ReadonlySet<NodeId>
  readonly interaction: InteractionState
  readonly snapGuides: readonly SnapGuide[]
  readonly nextZIndex: number
}
```

### BoardSnapshot

A serializable snapshot of the board. Differs from `BoardState` in that `nodes` is a sorted array and `selection` is an array.

```ts
interface BoardSnapshot<R extends NodeTypeRegistry = NodeTypeRegistry> {
  readonly camera: Camera
  readonly grid: GridSettings
  readonly nodes: readonly ResolvedNode<R>[]   // sorted by zIndex
  readonly selection: readonly NodeId[]
  readonly interaction: InteractionState
  readonly snapGuides: readonly SnapGuide[]
  readonly nextZIndex: number
}
```

## Snapping

### SnapAxis

```ts
type SnapAxis = 'x' | 'y'
```

### SnapGuide

An alignment guide displayed during drag/resize snapping.

```ts
interface SnapGuide {
  axis: SnapAxis     // which axis the guide runs along
  position: number   // position on the axis
  from: number       // start of the guide line (perpendicular axis)
  to: number         // end of the guide line
}
```

### SnapResult

Result of snapping bounds to nearby node edges during resize.

```ts
interface SnapResult {
  bounds: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>
  guides: SnapGuide[]
}
```

### DragSnapResult

Result of snapping a node position to nearby edges during drag.

```ts
interface DragSnapResult {
  dx: number         // adjusted horizontal delta
  dy: number         // adjusted vertical delta
  guides: SnapGuide[]
}
```

## Events

### BoardEventMap

The full event map. See the [event catalog](/api/board-core#event-catalog) for handler signatures and descriptions.

```ts
interface BoardEventMap<R extends NodeTypeRegistry = NodeTypeRegistry> {
  ready: () => void
  destroy: () => void
  'camera:change': (camera: Camera, prev: Camera) => void
  'node:created': (node: ResolvedNode<R>) => void
  'node:updated': (node: ResolvedNode<R>, prev: ResolvedNode<R>) => void
  'node:deleted': (id: NodeId, prev: ResolvedNode<R>) => void
  'node:moved': (node: ResolvedNode<R>, delta: Point) => void
  'node:resized': (node: ResolvedNode<R>, prev: Pick<ResolvedNode<R>, 'x' | 'y' | 'width' | 'height'>) => void
  'selection:change': (selected: NodeId[], prev: NodeId[]) => void
  'interaction:start': (state: InteractionState) => void
  'interaction:update': (state: InteractionState) => void
  'interaction:end': (state: InteractionState) => void
  'command:before': (name: string, args: unknown[]) => void
  'command:after': (name: string, args: unknown[], duration: number) => void
  'command:blocked': (name: string, args: unknown[]) => void
  'invariant:failed': (failure: InvariantFailure<R>) => void
}
```

## Plugins

### BoardPlugin

The plugin interface. Plugins have a name and an `install` function that receives the engine context.

```ts
interface BoardPlugin<R extends NodeTypeRegistry = NodeTypeRegistry> {
  name: string
  install(engine: BoardPluginContext<R>, options?: Record<string, unknown>): void | PluginCleanup
}
```

### BoardPluginContext

Extended engine interface available inside plugin `install` functions. Adds `emit()`, `extend()`, and `runCommand()`.

```ts
interface BoardPluginContext<R extends NodeTypeRegistry> extends BoardEngine<R> {
  emit<K extends keyof BoardEventMap<R>>(event: K, ...args: Parameters<BoardEventMap<R>[K]>): void
  extend<K extends keyof BoardEngineExtensions<R> & string>(key: K, value: BoardEngineExtensions<R>[K]): void
  runCommand<T>(name: string, args: unknown[], fn: () => T): T
}
```

| Method | Description |
| --- | --- |
| `emit(event, ...args)` | Emit a custom or built-in event on the engine. |
| `extend(key, value)` | Register an API extension on `engine.ext`. |
| `runCommand(name, args, fn)` | Execute a named command through the full pipeline (middleware, events, invariants). |

### BoardEngineExtensions

Extensible interface populated by plugins via `context.extend()`. Use TypeScript module augmentation to add type-safe extensions.

```ts
interface BoardEngineExtensions<R extends NodeTypeRegistry = NodeTypeRegistry> {}
```

```ts
// In your plugin's type declaration:
declare module '@lupinum/board-core' {
  interface BoardEngineExtensions<R extends NodeTypeRegistry> {
    myPlugin: { doSomething(): void }
  }
}
```

### BoardEngineOptions

See the [options table](/api/board-core#options) on the main board-core page.

### PluginCleanup

A cleanup function returned by `install()`.

```ts
type PluginCleanup = () => void
```

### Unsubscribe

A function that removes a subscription or listener.

```ts
type Unsubscribe = () => void
```

### CommandMiddleware

A function that intercepts engine commands. Call `next()` to proceed, omit it to block.

```ts
type CommandMiddleware = (name: string, args: unknown[], next: () => void) => void
```

## Diagnostics

### InvariantMode

Controls how state validation failures are handled.

```ts
type InvariantMode = 'strict' | 'warn' | 'off'
```

| Value | Behavior |
| --- | --- |
| `'strict'` | Throws an error on invariant violation. |
| `'warn'` | Logs a warning and emits `invariant:failed`. |
| `'off'` | Skips validation entirely. |

### InvariantFailure

Information about a state invariant violation.

```ts
interface InvariantFailure<R extends NodeTypeRegistry = NodeTypeRegistry> {
  name: string              // invariant name
  message: string           // human-readable description
  snapshot: BoardSnapshot<R> // board state when the failure occurred
  context: string           // which command triggered the validation
}
```

### TraceEntry

A single entry in the diagnostic event trace.

```ts
interface TraceEntry {
  event: string      // event name (e.g. 'node:created')
  timestamp: number  // Date.now() when the event fired
  args: unknown[]    // event arguments
}
```
