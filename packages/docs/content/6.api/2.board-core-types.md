## Persisted Documents

Persisted board data uses `JsonCanvasDocument`.

```ts
interface JsonCanvasDocument {
  readonly nodes: readonly JsonCanvasNode[]
  readonly edges?: readonly JsonCanvasEdge[]
  readonly 'x-nuxt-board'?: NuxtBoardDocumentMetadata
}
```

Core owns node persistence and board metadata. Installed plugins may contribute their own document fields through the plugin persistence hook. Runtime-only snapshot fields such as `camera`, `grid`, and `selection` are not accepted as top-level persisted document fields.

## Runtime Snapshots

`BoardSnapshot` is for renderers, tests, and UI reads.

```ts
interface BoardSnapshot {
  readonly camera: Camera
  readonly grid: GridSettings
  readonly nodes: readonly BoardNode[]
  readonly selection: readonly NodeId[]
  readonly interaction: InteractionState
  readonly snapGuides: readonly SnapGuide[]
  readonly nextZIndex: number
}
```

Use `engine.exportJSON()` and `engine.importJSON()` for persistence.

## BoardNode

```ts
interface BoardNode {
  readonly id: NodeId
  readonly type: JsonCanvasNodeType
  readonly x: number
  readonly y: number
  readonly width: number
  readonly height: number
  readonly text?: string
  readonly file?: string
  readonly url?: string
  readonly label?: string
  readonly zIndex: number
  readonly locked: boolean
  readonly visible: boolean
  readonly parentId?: NodeId
  readonly data?: NodeData
}
```

`data` is a runtime compatibility projection for older renderers. New persisted behavior should use JSON Canvas node fields.

## Plugin Persistence

Plugins that own persisted data implement `BoardPluginPersistence`.

```ts
interface BoardPluginPersistence {
  exportDocument?(
    engine: BoardPluginContext,
  ): Partial<JsonCanvasDocument> | void
  importDocument?(
    engine: BoardPluginContext,
    document: JsonCanvasDocument,
    mode: 'replace' | 'merge',
    idMap: ReadonlyMap<NodeId, NodeId>,
  ): void
}
```

Core validates the document and restores nodes first. Plugins then receive the same document plus the node id remapping produced by merge imports.
