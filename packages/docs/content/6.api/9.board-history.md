## historyPlugin

Creates the history plugin. Install it during engine creation or at runtime with `engine.use()`.

```ts
function historyPlugin(options?: HistoryPluginOptions): BoardPlugin
```

### Options

| Name         | Type       | Default | Description                                                                        |
| ------------ | ---------- | ------- | ---------------------------------------------------------------------------------- |
| `maxSteps`   | `number`   | `200`   | Maximum number of undo steps to retain.                                            |
| `debounceMs` | `number`   | `300`   | Debounce window for coalescing rapid changes into a single undo step.              |
| `exclude`    | `string[]` | `[]`    | Additional command names to exclude from history (beyond the built-in exclusions). |

```ts
import { createBoardEngine } from '@lupinum/board-core'
import { historyPlugin } from '@lupinum/board-history'

const engine = createBoardEngine({
  plugins: [historyPlugin({ maxSteps: 100, debounceMs: 500 })],
})
```

### Default excluded commands

These commands are never recorded in history (they are ephemeral interactions or camera operations):

`panBy`, `panTo`, `zoomAt`, `zoomTo`, `zoomToFit`, `zoomToNodes`, `beginPan`, `beginNodeDrag`, `beginResize`, `beginBoxSelect`, `beginTextEdit`, `endInteraction`

## Extension API

After installing the plugin, the history API is available on `engine.ext.history`.

### undo

Restores the previous state. No-op if there is nothing to undo.

```ts
undo(): void
```

```ts
engine.ext.history.undo()
```

### redo

Re-applies the next state. No-op if there is nothing to redo.

```ts
redo(): void
```

### canUndo

Returns `true` if there is at least one undo step available.

```ts
canUndo(): boolean
```

### canRedo

Returns `true` if there is at least one redo step available.

```ts
canRedo(): boolean
```

### clear

Clears the entire history stack (both undo and redo).

```ts
clear(): void
```

### getState

Returns the current history state.

```ts
getState(): HistoryState
```

```ts
const state = engine.ext.history.getState()
console.log(`${state.undoDepth} undo steps, ${state.redoDepth} redo steps`)
```

## Debouncing Behavior

The history plugin debounces rapid changes to avoid flooding the undo stack. When multiple commands fire within the `debounceMs` window, they are coalesced into a single undo step. This means dragging a node produces one undo step, not hundreds.

The debounce timer resets on each new command. A new history entry is only pushed when the debounce window expires without further changes.

---

## Connection-Aware Restoration

When the connections plugin is also installed, the history plugin automatically captures and restores edge state. Undoing a node deletion also restores any edges that were connected to that node.

## Types

### HistoryState

```ts
interface HistoryState {
  undoDepth: number // number of undo steps available
  redoDepth: number // number of redo steps available
  current: string | null // label of the current history entry
}
```

### HistoryEntry

```ts
interface HistoryEntry {
  label: string // command name that created this entry
  snapshot: BoardSnapshot // full board state at this point
  extras?: Record<string, unknown> // plugin state (e.g. edges)
  timestamp: number // Date.now() when the entry was created
}
```

### HistoryPluginOptions

```ts
interface HistoryPluginOptions {
  maxSteps?: number // default: 200
  debounceMs?: number // default: 300
  exclude?: string[] // additional commands to ignore
}
```

## Events

The history plugin adds these events to `BoardEventMap`:

| Event           | Handler                                 | Description                              |
| --------------- | --------------------------------------- | ---------------------------------------- |
| `history:push`  | `(entry: HistoryEntry) => void`         | A new entry was added to the undo stack. |
| `history:undo`  | `(entry: HistoryEntry \| null) => void` | An undo operation was performed.         |
| `history:redo`  | `(entry: HistoryEntry \| null) => void` | A redo operation was performed.          |
| `history:clear` | `() => void`                            | The history stack was cleared.           |

```ts
engine.on('history:push', (entry) => {
  console.log('New undo step:', entry.label)
})

engine.on('history:undo', () => {
  console.log('Undo depth:', engine.ext.history.getState().undoDepth)
})
```
