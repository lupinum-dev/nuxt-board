---
title: '@lupinum/board-core'
description: 'The supported public API for the headless board engine.'
---

`@lupinum/board-core` exports the engine factory, public board types, JSON Canvas
document types, color helpers, and selection helpers.

It does not expose the first-party action replay system, reducers, feature
persistence hooks, or command inversion helpers as stable consumer API.

## createBoardEngine

```ts
import { createBoardEngine } from '@lupinum/board-core'

const engine = createBoardEngine({
  grid: { size: 24, snap: true },
})
```

Install first-party packages with `extensions`.

```ts
const engine = createBoardEngine({
  extensions: [historyPlugin(), connectionPlugin()],
})
```

## Nodes

Nodes use JSON Canvas fields directly.

```ts
engine.createNode({
  type: 'text',
  x: 120,
  y: 80,
  width: 240,
  height: 120,
  text: 'Release plan',
})
```

Supported node fields are `text`, `file`, `subpath`, `url`, `label`,
`background`, and `backgroundStyle`. There is no legacy data compatibility layer.

## Persistence

Use `exportJSON()` and `importJSON()` for persisted documents.

```ts
const json = engine.exportJSON()
engine.importJSON(json, 'replace')
```

Core persists nodes and board metadata. Edges belong to
`@lupinum/board-connections`; importing a document with edges without that
connections package installed fails instead of dropping edge data.

## Public Helpers

The public helpers are the helpers consumers need to build boards:

- color helpers such as `BOARD_COLOR_PRESETS`, `colorForPreset`, and
  `isBoardColorPreset`
- id helpers such as `asNodeId` and `asEdgeId`
- selection helpers such as `getSelectionNodes`, `getSelectionBounds`, and
  `toggleIds`
- geometry helpers used by renderers and overlays
