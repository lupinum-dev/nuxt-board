## Publishing

- CI validates linting, unit tests, docs, pack smoke tests, and browser coverage.
- Changesets manages version files and changelog-ready release PRs.
- The release workflow publishes the public packages from `main`.

## Deployment

- `.github/workflows/docs.yml` deploys preview docs on pull requests and production docs from `main` when `VERCEL_TOKEN`, `VERCEL_ORG_ID`, and `VERCEL_PROJECT_ID` are configured.
- Set `NUXT_PUBLIC_SITE_URL` for the production deployment so canonical URLs and social metadata resolve to your chosen domain.
