---
title: "@lupinum/board-selection"
description: "Selection helpers for current snapshots."
---

## Install

```bash
pnpm add @lupinum/board-selection @lupinum/board-core
```

## Exports

| Name | Kind | Notes |
| --- | --- | --- |
| `getSelectionBounds` | Function | Compute the bounding box of the current selection, or `null` when empty. |
| `getSelectionNodes` | Function | Return the currently selected nodes in snapshot order. |
| `toggleIds` | Function | Toggle a list of ids in an existing selection array. |
