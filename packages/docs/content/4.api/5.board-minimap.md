---
title: "@lupinum/board-minimap"
description: "Minimap composable and renderer for large boards."
---

## Install

```bash
pnpm add @lupinum/board-minimap @lupinum/vue-board
```

## Exports

| Name | Kind | Notes |
| --- | --- | --- |
| `BoardMinimap` | Component / object | Render a clickable, draggable minimap for the current board engine. |
| `MinimapOptions` | Type | Sizing options for the minimap composable and component. |
| `useMinimap` | Composable | Project board content and the active viewport into minimap coordinates. |
