title: "@lupinum/board-serializer"
description: "JSON Canvas import and export helpers."
---

## Install

```bash
pnpm add @lupinum/board-serializer @lupinum/board-core
```

## Exports

| Name | Kind | Notes |
| --- | --- | --- |
| `createJsonCanvasSerializer` | Factory | Create an isolated JSON Canvas serializer instance with its own type registry. |
| `JsonCanvasDocument` | Type | JSON Canvas document with optional `x-canvas` extensions used by this library. |
| `JsonCanvasEdge` | Type | Serializable JSON Canvas edge entry. |
| `JsonCanvasNode` | Type | Serializable JSON Canvas node entry plus optional extension keys. |
| `jsonCanvasSerializer` | Function | Default serializer instance for convenience. |
| `JsonCanvasSerializer` | Type | Serializer contract for importing and exporting JSON Canvas documents. |
| `TypeHandler` | Type | Custom serializers for non-text node types. |
