---
title: "@lupinum/board-history"
description: "Undo and redo support."
---

## Install

```bash
pnpm add @lupinum/board-history @lupinum/board-core
```

## Exports

| Name | Kind | Notes |
| --- | --- | --- |
| `HistoryEntry` | Type | A single undoable history frame captured from dispatched actions. |
| `historyPlugin` | Plugin | Install undo/redo support backed by inverse action replay. |
| `HistoryPluginOptions` | Type | Options for configuring stack depth and move coalescing. |
| `HistoryState` | Type | Public history state exposed by the history plugin extension. |
