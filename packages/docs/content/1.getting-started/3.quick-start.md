This is the shortest path from install to a working board. Pick Vue or Nuxt where the setup differs, but keep the same mental model.

::tip
If you store the engine in Vue state, use `shallowRef(engine)`. Do not wrap the engine in `reactive()`.
::

::code-tree{defaultValue="App.vue"}

```vue [App.vue]
<script setup lang="ts">
import { createBoardEngine } from '@lupinum/board-core'
import { BoardRoot } from '@lupinum/vue-board'

const engine = createBoardEngine({
  grid: { size: 20, snap: true }
})

engine.createNode({
  type: 'text',
  x: 80, y: 80,
  width: 240, height: 120,
  data: { content: 'Hello board' }
})
</script>

<template>
  <BoardRoot :engine="engine" class="h-screen" />
</template>
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-board']
})
```

::

## Try these interactions

- Drag a node to move it.
- Resize from a corner handle.
- :kbd{value="meta"} :kbd{value="scroll"} to zoom.
- Double-click empty space to create a node.
- Double-click a node to edit text.
- :kbd{value="Delete"} or :kbd{value="Backspace"} to delete the selection.

::collapsible
### What just happened?

`createBoardEngine()` created the headless state container. `createNode()` pushed the first record through the command pipeline. `BoardRoot` subscribed to the engine and rendered the interaction layer on top of that state.
