Vue Board is a node-based board toolkit for products that need spatial editing — whiteboards, workflow builders, graph editors, planning tools, and anything that puts things on an infinite canvas.

## What You Can Build

- **Whiteboards** — freeform brainstorming with cards, groups, and connections
- **Workflow editors** — pipeline builders with typed steps and directed edges
- **Graph viewers** — dependency visualizations, mind maps, and entity diagrams
- **Planning tools** — kanban boards, sprint planners, and roadmap canvases
- **Diagram editors** — architecture diagrams with custom node types

## Architecture

The library is engine-first: the core has zero DOM or framework dependencies. Vue rendering is an adapter layer.

```
@lupinum/board-core        Headless engine, state, commands, types
    ↓
@lupinum/vue-board          Vue 3 components and composables
    ↓
@lupinum/nuxt-board         Nuxt module with auto-imports
```

Plugins add capabilities without coupling to the engine:

| Package | What it adds |
| --- | --- |
| `@lupinum/board-history` | Undo/redo with debouncing |
| `@lupinum/board-connections` | Edges between nodes with routing |
| `@lupinum/board-minimap` | Minimap composable and component |
| `@lupinum/board-selection` | Selection utility functions |
| `@lupinum/board-serializer` | JSON Canvas import/export |

## Design Principles

- **Engine-first** — the core owns all state and commands. Rendering is a subscriber.
- **Immutable state** — nodes are frozen records. All mutation goes through commands.
- **Type-safe** — generic type parameters ensure node data matches its type.
- **Plugin architecture** — capabilities are added through a clean plugin interface, not monolithic configuration.
- **Framework-agnostic core** — `board-core` has no Vue dependency. Adapters for other frameworks are possible.
