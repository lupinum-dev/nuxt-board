Vue Board helps you build interactive node canvases without hiding the board model inside a component.

The core package owns board state, commands, validation, snapshots, and JSON Canvas import/export. Vue renders the board. Plugins add focused features such as connections, history, and minimaps.

::note
The engine is framework-agnostic. It stores nodes, camera state, selection, interaction state, snap guides, command guards, and events.
::

## Package Model

Install the smallest set that matches the surface you are building.

| Package                      | Role                                                                                            |
| ---------------------------- | ----------------------------------------------------------------------------------------------- |
| `@lupinum/board-core`        | Headless state, commands, hierarchy, selection, camera, command guards, and events.             |
| `@lupinum/vue-board`         | Vue board shell, default node rendering, selection toolbar, interaction layer, and composables. |
| `nuxt-board`                 | Nuxt module that auto-imports board components and composables.                                 |
| `@lupinum/board-connections` | Edges, labels, anchors, routing, and connection UI.                                             |
| `@lupinum/board-history`     | Undo and redo for engine commands.                                                              |
| `@lupinum/board-minimap`     | Overview/minimap UI.                                                                            |

## How the Pieces Fit

`createBoardEngine()` creates the board model. `BoardRoot` subscribes to that model and renders nodes, interaction affordances, grid, selection state, and LOD placeholders.

Your application code should mutate the board through engine commands:

```ts
const card = engine.createNode({
  type: 'text',
  x: 80,
  y: 80,
  width: 260,
  height: 140,
  color: '5',
  text: 'Node',
})

engine.updateNode(card.id, {
  text: 'Node',
})
```

Those commands keep guards, events, history, and validation on the same path.
