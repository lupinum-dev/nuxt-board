Vue Board is for products that want spatial interaction without welding the UI into the engine. The core owns state and commands, Vue renders it, and plugins stay optional.

::note
The engine is headless. It owns nodes, camera state, selection, commands, and events. Vue is the rendering layer.
::

## Architecture

`@lupinum/board-core` owns the board model and command pipeline. `@lupinum/vue-board` renders that model into Vue components. `@lupinum/nuxt-board` removes the import ceremony when you are in Nuxt.
