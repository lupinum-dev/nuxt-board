Vue Board is a node-based board toolkit for products that need spatial editing. That includes whiteboards, workflow builders, graph editors, and internal planning tools.

## Package map

- `@lupinum/board-core` owns the engine, math helpers, and immutable board state.
- `@lupinum/vue-board` renders and wires the board into Vue 3.
- `@lupinum/nuxt-board` brings the same surface to Nuxt with auto-imported components and composables.
- The support packages add history, selection helpers, connections, minimaps, and JSON Canvas import/export.

## Design bias

- Hard cutovers over compatibility layers.
- Small abstractions over framework-shaped wrappers.
- Pluginable behavior without hiding core state or commands.
