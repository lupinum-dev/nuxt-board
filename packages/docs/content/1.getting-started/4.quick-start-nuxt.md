## 1. Install and register

```bash
pnpm add @lupinum/nuxt-board
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-board'],
})
```

## 2. Use without imports

With the module registered, `createBoardEngine`, `BoardRoot`, and all composables are available globally:

```vue [app.vue]
<script setup lang="ts">
const engine = createBoardEngine({
  grid: { size: 20, snap: true },
})

engine.createNode({
  type: 'text',
  x: 96, y: 96,
  width: 240, height: 120,
  data: { content: 'Nuxt auto-imported this API.' },
})
</script>

<template>
  <BoardRoot :engine="engine" class="h-screen" />
</template>
```

No `import { createBoardEngine } from '...'` needed.

## 3. What's auto-imported

| Category | Items |
| --- | --- |
| **Components** | `BoardRoot`, `BoardViewport`, `BoardNode`, `BoardNodeHandle`, `BoardGrid`, `BoardBoxSelect`, `BoardSnapGuides` |
| **Composables** | `useBoardEngine`, `useCamera`, `useNodes`, `useSelection`, `useInteraction`, `useVisibleBounds`, `useVisibleNodes`, `useGridStyle`, `useNode`, `useBoxSelectBounds` |
| **Functions** | `createBoardEngine` |

## Module Options

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-board'],
  board: {
    prefix: 'My',                  // <MyBoardRoot> instead of <BoardRoot>
    autoImportComponents: true,    // default: true
    autoImportComposables: true,   // default: true
  },
})
```

## Difference from the Vue setup

| | Vue | Nuxt |
| --- | --- | --- |
| Install | `@lupinum/vue-board` + `@lupinum/board-core` | `@lupinum/nuxt-board` |
| Imports | Manual `import { BoardRoot, createBoardEngine }` | Auto-imported |
| Config | None | `board` key in `nuxt.config.ts` |
| Component prefix | N/A | Configurable via `prefix` option |
