## 1. Create the engine

```ts
import { createBoardEngine } from '@lupinum/board-core'

const engine = createBoardEngine({
  grid: { size: 20, snap: true },
})
```

The engine is the single source of truth for the board. It's headless — no DOM dependency.

## 2. Add initial nodes

```ts
engine.createNode({
  type: 'text',
  x: 80, y: 80,
  width: 240, height: 120,
  data: { content: 'Hello board' },
})
```

Or pass `initialNodes` to the constructor for deterministic seeding (useful for SSR).

## 3. Mount the board

```vue
<script setup lang="ts">
import { createBoardEngine } from '@lupinum/board-core'
import { BoardRoot } from '@lupinum/vue-board'

const engine = createBoardEngine({
  grid: { size: 20, snap: true },
})

engine.createNode({
  type: 'text',
  x: 80, y: 80,
  width: 240, height: 120,
  data: { content: 'Hello board' },
})
</script>

<template>
  <BoardRoot :engine="engine" class="h-screen" />
</template>
```

## 4. Interact

Out of the box, you can:

- **Drag** nodes to move them
- **Resize** using the corner/edge handles
- **Scroll** to pan the canvas
- **Ctrl/Cmd + Scroll** to zoom
- **Double-click** empty space to create a new node
- **Double-click** a node to edit its text
- **Box select** by dragging on empty space
- **Delete/Backspace** to delete selected nodes
