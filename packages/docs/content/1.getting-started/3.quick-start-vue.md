```vue [App.vue]
<script setup lang="ts">
import { createBoardEngine } from '@lupinum/board-core'
import { BoardRoot } from '@lupinum/vue-board'

const engine = createBoardEngine({
  initialNodes: [
    { id: 'start' as never, type: 'text', x: 80, y: 80, width: 240, height: 120, data: { content: 'Hello board' }, zIndex: 1, locked: false, visible: true }
  ]
})
</script>

<template>
  <BoardRoot :engine="engine" class="h-screen" />
</template>
```

Once the root is mounted, you can layer in custom renderers, commands, plugins, and serialization.
