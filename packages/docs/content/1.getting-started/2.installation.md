Install the smallest package set that matches your app. Then verify it by touching a live board immediately.

::steps{level="3"}

### Pick Vue or Nuxt

::tabs

:::tabs-item{label="pnpm" icon="i-lucide-terminal"}
```bash
pnpm add @lupinum/vue-board @lupinum/board-core
```
:::

:::tabs-item{label="npm" icon="i-lucide-terminal"}
```bash
npm install @lupinum/vue-board @lupinum/board-core
```
:::

:::tabs-item{label="yarn" icon="i-lucide-terminal"}
```bash
yarn add @lupinum/vue-board @lupinum/board-core
```
:::

::

If you use Nuxt instead, install the module:

```bash
pnpm add @lupinum/nuxt-board
```

### Register the module if you use Nuxt

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-board']
})
```

### Verify it works

```ts
import { createBoardEngine } from '@lupinum/board-core'

const engine = createBoardEngine()
console.log(engine.getState().camera.z)
```

::

::note
Plugins are installed separately. See the [plugins and middleware guide](/guides/plugins) when you actually need undo/redo, edges, a minimap, or serialization.
::
