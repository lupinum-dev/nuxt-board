## Vue

```bash
pnpm add @lupinum/vue-board @lupinum/board-core
```

Add plugins as needed:

```bash
pnpm add @lupinum/board-history @lupinum/board-connections @lupinum/board-minimap @lupinum/board-serializer
```

## Nuxt

```bash
pnpm add @lupinum/nuxt-board
```

Then register the module:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-board']
})
```
