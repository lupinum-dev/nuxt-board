## Vue 3

Install the core engine and Vue adapter:

::code-group
```bash [pnpm]
pnpm add @lupinum/vue-board @lupinum/board-core
```
```bash [npm]
npm install @lupinum/vue-board @lupinum/board-core
```
```bash [yarn]
yarn add @lupinum/vue-board @lupinum/board-core
```
::

### Optional plugins

Add only the plugins you need:

```bash
pnpm add @lupinum/board-history        # undo/redo
pnpm add @lupinum/board-connections    # edges between nodes
pnpm add @lupinum/board-minimap        # minimap
pnpm add @lupinum/board-selection      # selection utilities
pnpm add @lupinum/board-serializer     # JSON Canvas import/export
```

## Nuxt 3

The Nuxt module installs the Vue adapter and core automatically:

::code-group
```bash [pnpm]
pnpm add @lupinum/nuxt-board
```
```bash [npm]
npm install @lupinum/nuxt-board
```
::

Register the module:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-board'],
})
```

Components, composables, and `createBoardEngine` are auto-imported — no manual imports needed.

## Verify Installation

```ts
import { createBoardEngine } from '@lupinum/board-core'

const engine = createBoardEngine()
console.log(engine.getState()) // { camera, nodes, selection, ... }
```

## TypeScript

All packages ship with TypeScript declarations. No `@types/*` packages are needed.
