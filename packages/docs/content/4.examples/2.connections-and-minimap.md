## What’s happening

This example layers the connections, history, and minimap plugins onto a normal board. The important part is that none of those concerns leak into the engine core until you install them.

## The code

::code-tree{defaultValue="app.vue"}

```vue [app.vue]
<script setup lang="ts">
import { historyPlugin } from '@lupinum/board-history'
import {
  connectionPlugin,
  BoardConnectionLayer,
} from '@lupinum/board-connections'
import { BoardMinimap } from '@lupinum/board-minimap'

const engine = createBoardEngine({
  extensions: [historyPlugin(), connectionPlugin()],
})
</script>

<template>
  <BoardRoot :engine="engine">
    <BoardConnectionLayer routing="step" />
    <template #default>
      <BoardMinimap :width="180" :height="110" />
    </template>
  </BoardRoot>
</template>
```

::

## Try these things

- Switch between `Bezier`, `Step`, and `Straight`.
- Shuffle the layout and watch the edges and minimap update.
- Undo and redo a few changes with the toolbar.
