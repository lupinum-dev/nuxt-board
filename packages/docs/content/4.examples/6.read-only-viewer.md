## What’s happening

This example uses middleware as a policy layer. The board still renders and the camera still moves, but mutation commands exit early when read-only mode is enabled.

## The code

::steps{level="3"}

### Load the scene

```ts
const engine = createBoardEngine()
engine.importJSON(savedBoardJson, 'replace')
```

### Block mutation commands

```ts
const blocked = new Set([
  'beginNodeDrag',
  'beginResize',
  'beginTextEdit',
  'createNode',
  'updateNode',
  'deleteSelected',
])

const stopReadOnly = engine.addMiddleware((name, _args, next) => {
  if (blocked.has(name)) return
  next()
})
```

### Remove the middleware to restore editing

```ts
stopReadOnly()
```

::

## Try these things

- Leave the demo in read-only mode and try dragging or deleting a node.
- Toggle back to edit mode and repeat the same action.
- Watch the blocked command counter increment when middleware rejects a mutation.
