## What’s happening

This example mixes the default text renderer with two fully custom node types. The board shell still handles interaction, selection, and layout. Only the node content changes.

## The code

::code-tree{defaultValue="app.vue"}

```ts [app.vue]
import DocsInsightNode from './DocsInsightNode.vue'
import DocsMetricNode from './DocsMetricNode.vue'

const renderers = {
  insight: DocsInsightNode,
  metric: DocsMetricNode
}
```

```vue [template.vue]
<BoardRoot :engine="engine" :renderers="renderers" />
```

::

## Try these things

- Add an insight card and a metric card.
- Compare them with the default text node on the same board.
- Resize all three types and notice the interaction model stays the same.
