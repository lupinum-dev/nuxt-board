The camera controls what you see. It has three values: `x` and `y` for position, and `z` for zoom where `1` means 100%. The default zoom range is `0.1` to `8`.

```ts
const engine = createBoardEngine({
  camera: { x: 0, y: 0, z: 1 },
  zoom: { min: 0.1, max: 8 },
})
```

## Panning

```ts
engine.panBy(100, 0)                     // pan right by 100 world units
engine.panBy(0, -50)                     // pan up by 50

await engine.panTo({ x: 500, y: 300 })           // instant
await engine.panTo({ x: 500, y: 300 }, true)      // animated
```

## Zooming

```ts
engine.zoomAt({ x: 640, y: 360 }, -50)  // zoom in at a screen point
engine.zoomAt({ x: 640, y: 360 }, 50)   // zoom out at a screen point

await engine.zoomTo(2, true)             // zoom to 200%, animated
await engine.zoomTo(0.5, true)           // zoom to 50%, animated
await engine.zoomTo(1)                   // zoom to 100%, instant

await engine.zoomToFit(40, true)         // fit all nodes with 40px padding
await engine.zoomToNodes([nodeA, nodeB], 40, true)  // fit specific nodes
```

::tip
All animated methods return a `Promise` that resolves when the transition finishes. Starting a new animation cancels any in-progress one.
::

## Coordinate conversion

Convert between screen-space (pixels relative to the board element) and world-space (the infinite canvas):

```ts
const worldPos = engine.screenToWorld({ x: event.clientX, y: event.clientY })
const screenPos = engine.worldToScreen({ x: node.x, y: node.y })
```

In Vue, use composables for reactive access:

```vue
<script setup lang="ts">
const bounds = useVisibleBounds()
const camera = useCamera()
</script>
```

## Camera events

```ts
engine.on('camera:change', (camera, prev) => {
  console.log(`Zoom: ${prev.z.toFixed(2)} → ${camera.z.toFixed(2)}`)
})
```

::note
Camera changes from panning and zooming are high-frequency. Consider throttling if you do expensive work in the handler.
::

::collapsible
### Viewport culling

`BoardRoot` only renders nodes within the viewport plus a margin. Nodes outside are completely unmounted from the DOM.

```vue
<BoardRoot :engine="engine" :cull-margin="300" />
```

The default margin is 200 world units. See the [performance guide](/guides/performance) for tuning.
::

::collapsible
### Viewport size

`BoardRoot` automatically tracks the viewport size via `ResizeObserver`. Read it with:

```ts
const { x: width, y: height } = engine.getViewportSize()
```
::

::collapsible
### Camera type definition

```ts
interface Camera {
  x: number  // horizontal offset in world units
  y: number  // vertical offset in world units
  z: number  // zoom level (1 = 100%)
}
```
