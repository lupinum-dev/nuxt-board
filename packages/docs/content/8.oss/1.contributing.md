## Principles

- Prefer deletion and simplification over wrappers.
- Avoid compatibility shims during refactors.
- Keep public API changes covered by docs and tests.

## Workflow

```bash
pnpm install
pnpm docs:api
pnpm test:unit
pnpm test:e2e
```

Create a changeset for publishable package changes:

```bash
pnpm changeset
```
