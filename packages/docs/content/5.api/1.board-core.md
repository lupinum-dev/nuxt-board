## createBoardEngine

Creates a new board engine instance. This is the entry point for every board.

```ts
import { createBoardEngine } from '@lupinum/board-core'

const engine = createBoardEngine({
  grid: { size: 20, snap: true, pattern: 'line' },
  plugins: [historyPlugin(), connectionPlugin()],
})
```

### Options

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `camera` | `Partial<Camera>` | `{ x: 0, y: 0, z: 1 }` | Initial camera position and zoom level. |
| `zoom` | `Partial<ZoomSettings>` | `{ min: 0.1, max: 8 }` | Allowed zoom range. |
| `grid` | `Partial<GridSettings>` | `{ size: 10, majorEvery: 5, snap: true, pattern: 'line' }` | Grid size, snap behavior, and visual pattern. |
| `nodes` | `Partial<NodeConstraints>` | `{ minWidth: 50, minHeight: 50, defaultWidth: 240, defaultHeight: 160 }` | Constraints for node dimensions. |
| `plugins` | `BoardPlugin<R>[]` | `[]` | Plugins to install during creation. |
| `diagnostics` | `boolean \| { traceLimit?: number }` | `true` | Enable command tracing. Set `traceLimit` to control buffer size (default 500). |
| `invariants` | `InvariantMode` | `'strict'` | `'strict'` throws on invalid state, `'warn'` logs, `'off'` disables checks. |
| `initialNodes` | `ReadonlyArray<ResolvedNode<R>>` | `[]` | Seed nodes to populate the board before the first render. |

### Type parameter

The engine accepts a generic `R extends NodeTypeRegistry` that maps node type strings to their data shape. This enables type-safe node creation and updates:

```ts
type MyRegistry = {
  text: { content: string }
  image: { src: string; alt: string }
  group: { title: string; accent: string }
}

const engine = createBoardEngine<MyRegistry>({
  grid: { size: 24, snap: true },
})

// Type-safe: data must match the 'text' shape
engine.createNode({ type: 'text', x: 0, y: 0, data: { content: 'Hello' } })
```

## Reactive State (Subscribables)

The engine exposes five reactive channels. Each is a `Subscribable<T>` with `get()` and `subscribe()` methods. In Vue, the `@lupinum/vue-board` composables wrap these into computed refs automatically.

| Subscribable | Type | Description |
| --- | --- | --- |
| `$camera` | `Subscribable<Camera>` | Current camera position `{ x, y, z }` where `z` is zoom. |
| `$nodes` | `Subscribable<ReadonlyMap<NodeId, ResolvedNode<R>>>` | All nodes keyed by ID. |
| `$selection` | `Subscribable<ReadonlySet<NodeId>>` | Currently selected node IDs. |
| `$interaction` | `Subscribable<InteractionState>` | Current interaction mode (idle, panning, dragging, etc.). |
| `$snapGuides` | `Subscribable<readonly SnapGuide[]>` | Active snap alignment guides during drag/resize. |

```ts
// Read current value
const camera = engine.$camera.get()

// Subscribe to changes
const unsub = engine.$camera.subscribe((current, prev) => {
  console.log('Camera moved from', prev, 'to', current)
})

// Clean up
unsub()
```

## State Access

### getState

Returns a snapshot of the full board state.

```ts
getState(): BoardState<R>
```

```ts
const state = engine.getState()
console.log(state.camera, state.nodes.size, state.selection.size)
```

### getSnapshot

Returns a serializable snapshot suitable for persistence or history.

```ts
getSnapshot(): BoardSnapshot<R>
```

```ts
const snapshot = engine.getSnapshot()
// snapshot.nodes is a sorted array, not a Map
```

### getGridSettings

Returns the current grid configuration.

```ts
getGridSettings(): GridSettings
```

### getViewportSize

Returns the viewport dimensions used for coordinate conversion.

```ts
getViewportSize(): Point
```

### getNode

Returns a node by ID. Throws if the node does not exist.

```ts
getNode(id: NodeId): ResolvedNode<R>
```

```ts
const node = engine.getNode(myId)
console.log(node.x, node.y, node.data)
```

### findNode

Returns a node by ID, or `null` if it does not exist.

```ts
findNode(id: NodeId): ResolvedNode<R> | null
```

### hasNode

Returns `true` if a node with the given ID exists.

```ts
hasNode(id: NodeId): boolean
```

### getNodeAt

Returns the topmost visible node at a world-space point, or `null`.

```ts
getNodeAt(worldPoint: Point): ResolvedNode<R> | null
```

```ts
const node = engine.getNodeAt({ x: 100, y: 200 })
```

### getNodesInBounds

Returns all visible nodes that intersect the given world-space bounds.

```ts
getNodesInBounds(bounds: Bounds): ResolvedNode<R>[]
```

### getSelection

Returns the currently selected node IDs as an array.

```ts
getSelection(): NodeId[]
```

## Node Operations

### createNode

Creates a new node and adds it to the board. Returns the created node. If `id` is omitted, a UUID is generated. If `select` is `true`, the node is selected after creation.

```ts
createNode<T extends keyof R>(input: NodeInput<R, T>): ResolvedNode<R, T>
```

| Parameter | Type | Description |
| --- | --- | --- |
| `input.id` | `NodeId` | Optional. Auto-generated UUID if omitted. |
| `input.type` | `string` | Node type key (e.g. `'text'`, `'image'`). Defaults to `'text'`. |
| `input.x` | `number` | X position. Defaults to `0`. |
| `input.y` | `number` | Y position. Defaults to `0`. |
| `input.width` | `number` | Width. Defaults to `NodeConstraints.defaultWidth`. |
| `input.height` | `number` | Height. Defaults to `NodeConstraints.defaultHeight`. |
| `input.data` | `R[T]` | Type-safe payload for this node type. |
| `input.locked` | `boolean` | Whether the node is locked. Defaults to `false`. |
| `input.visible` | `boolean` | Whether the node is visible. Defaults to `true`. |
| `input.parentId` | `NodeId` | Parent group node ID for hierarchy. |
| `input.select` | `boolean` | Select the node after creation. Defaults to `false`. |

```ts
const node = engine.createNode({
  type: 'text',
  x: 100, y: 200,
  width: 240, height: 160,
  data: { content: 'New card' },
  select: true,
})
```

### updateNode

Applies a partial update to a node. Returns the updated node.

```ts
updateNode<T extends keyof R>(id: NodeId, patch: NodePatch<R, T>): ResolvedNode<R, T>
```

```ts
engine.updateNode(nodeId, {
  x: 300, y: 400,
  data: { content: 'Updated text' },
})
```

### deleteNode

Removes a node from the board. Also deletes all descendants if the node is a group.

```ts
deleteNode(id: NodeId): void
```

### moveNode

Moves a node by a delta. Returns the moved node.

```ts
moveNode(id: NodeId, dx: number, dy: number): ResolvedNode<R>
```

```ts
engine.moveNode(nodeId, 50, -20) // move right 50, up 20
```

### translateSelectedNodes

Moves all selected nodes by a delta. Automatically handles group propagation.

```ts
translateSelectedNodes(dx: number, dy: number): void
```

### resizeNode

Resizes a node using a resize handle direction and delta. Returns the resized node.

```ts
resizeNode(id: NodeId, handle: ResizeHandle, dx: number, dy: number): ResolvedNode<R>
```

```ts
engine.resizeNode(nodeId, 'se', 40, 30) // expand south-east
```

### bringToFront

Moves a node to the highest z-index.

```ts
bringToFront(id: NodeId): void
```

### sendToBack

Moves a node to the lowest z-index.

```ts
sendToBack(id: NodeId): void
```

### lockNode

Locks a node so it cannot be moved or resized.

```ts
lockNode(id: NodeId): void
```

### unlockNode

Unlocks a previously locked node.

```ts
unlockNode(id: NodeId): void
```

### duplicateNodes

Duplicates the given nodes with an optional offset. Returns the new nodes.

```ts
duplicateNodes(ids: NodeId[], offset?: Point): ResolvedNode<R>[]
```

```ts
const clones = engine.duplicateNodes([nodeA, nodeB], { x: 20, y: 20 })
```

### copySelected

Copies selected nodes to an internal clipboard. Returns the copied nodes.

```ts
copySelected(): ResolvedNode<R>[]
```

### pasteClipboard

Pastes nodes from the internal clipboard with an optional offset. Returns the pasted nodes.

```ts
pasteClipboard(offset?: Point): ResolvedNode<R>[]
```

## Selection

### select

Selects one or more nodes. The `mode` parameter controls how the selection changes.

```ts
select(ids: NodeId | NodeId[], mode?: SelectionMode): void
```

| Mode | Behavior |
| --- | --- |
| `'replace'` | Replaces the current selection (default). |
| `'append'` | Adds to the current selection. |
| `'toggle'` | Toggles each ID in/out of the selection. |

```ts
engine.select(nodeId)                           // replace
engine.select([nodeA, nodeB], 'append')         // add to selection
engine.select(nodeId, 'toggle')                 // toggle
```

### selectAll

Selects all visible, unlocked nodes.

```ts
selectAll(): void
```

### clearSelection

Deselects all nodes.

```ts
clearSelection(): void
```

### deleteSelected

Deletes all selected nodes.

```ts
deleteSelected(): void
```

## Camera and Viewport

### panBy

Pans the camera by a world-space delta.

```ts
panBy(dx: number, dy: number): void
```

### panTo

Pans the camera to center on a world-space point. Optionally animates.

```ts
panTo(worldPoint: Point, animated?: boolean): Promise<void>
```

```ts
await engine.panTo({ x: 500, y: 300 }, true)
```

### zoomAt

Zooms relative to a screen-space point. Positive `delta` zooms out, negative zooms in.

```ts
zoomAt(screenPoint: Point, delta: number): void
```

### zoomTo

Sets the zoom level directly. Optionally animates.

```ts
zoomTo(level: number, animated?: boolean): Promise<void>
```

```ts
await engine.zoomTo(1.5, true)
```

### zoomToFit

Zooms and pans so all nodes fit in the viewport with optional padding.

```ts
zoomToFit(padding?: number, animated?: boolean): Promise<void>
```

```ts
await engine.zoomToFit(40, true)
```

### zoomToNodes

Zooms and pans to fit specific nodes in the viewport.

```ts
zoomToNodes(ids: NodeId[], padding?: number, animated?: boolean): Promise<void>
```

### screenToWorld

Converts a screen-space point to world-space coordinates using the current camera.

```ts
screenToWorld(point: Point): Point
```

```ts
const worldPos = engine.screenToWorld({ x: event.clientX, y: event.clientY })
```

### worldToScreen

Converts a world-space point to screen-space coordinates.

```ts
worldToScreen(point: Point): Point
```

### getVisibleBounds

Returns the world-space bounds currently visible in the viewport.

```ts
getVisibleBounds(width: number, height: number): Bounds
```

### setViewportSize

Updates the viewport dimensions used for coordinate conversion.

```ts
setViewportSize(size: Point): void
```

## Interaction

The engine models pointer interactions as a state machine with six modes. These methods drive the interaction FSM.

### beginPan

Starts a pan interaction.

```ts
beginPan(pointerId: number, screenPoint: Point): void
```

### beginNodeDrag

Starts dragging a node (and its selection group).

```ts
beginNodeDrag(id: NodeId, pointerId: number, screenPoint: Point): void
```

### beginResize

Starts resizing a node from a specific handle.

```ts
beginResize(id: NodeId, handle: ResizeHandle, pointerId: number, screenPoint: Point): void
```

### beginBoxSelect

Starts a box selection from a screen point.

```ts
beginBoxSelect(pointerId: number, screenPoint: Point): void
```

### beginTextEdit

Enters text editing mode for a node.

```ts
beginTextEdit(id: NodeId): void
```

### commitTextEdit

Commits text editing and returns to idle. Optionally updates the node's text content.

```ts
commitTextEdit(id: NodeId, text?: string): ResolvedNode<R>
```

### updatePointer

Updates the pointer position during an active interaction. Drives drag, resize, pan, and box select.

```ts
updatePointer(pointerId: number, screenPoint: Point, modifiers?: { shift?: boolean }): void
```

The `shift` modifier enables aspect-ratio-locked resizing when in `resizing-node` mode.

### endInteraction

Ends the current interaction and returns to idle.

```ts
endInteraction(pointerId?: number): void
```

## Batching

### batch

Groups multiple operations so subscribers receive a single notification at the end.

```ts
batch(fn: () => void): void
```

```ts
engine.batch(() => {
  engine.createNode({ type: 'text', x: 0, y: 0, data: { content: 'A' } })
  engine.createNode({ type: 'text', x: 300, y: 0, data: { content: 'B' } })
  // subscribers notified once, after both nodes exist
})
```

## Events

### on

Registers an event listener. Returns an unsubscribe function.

```ts
on<K extends keyof BoardEventMap<R>>(event: K, handler: BoardEventMap<R>[K]): Unsubscribe
```

```ts
const unsub = engine.on('node:created', (node) => {
  console.log('Created:', node.id, node.type)
})
```

### once

Registers a one-time event listener that auto-removes after the first call.

```ts
once<K extends keyof BoardEventMap<R>>(event: K, handler: BoardEventMap<R>[K]): Unsubscribe
```

### off

Removes an event listener.

```ts
off<K extends keyof BoardEventMap<R>>(event: K, handler: BoardEventMap<R>[K]): void
```

### Event catalog

| Event | Handler signature | When it fires |
| --- | --- | --- |
| `ready` | `() => void` | Engine initialization complete. |
| `destroy` | `() => void` | Engine is being torn down. |
| `camera:change` | `(camera, prev) => void` | Camera position or zoom changed. |
| `node:created` | `(node) => void` | A node was added to the board. |
| `node:updated` | `(node, prev) => void` | A node's properties changed. |
| `node:deleted` | `(id, prev) => void` | A node was removed. |
| `node:moved` | `(node, delta) => void` | A node changed position (subset of `node:updated`). |
| `node:resized` | `(node, prev) => void` | A node changed dimensions (subset of `node:updated`). |
| `selection:change` | `(selected, prev) => void` | The selection set changed. |
| `interaction:start` | `(state) => void` | An interaction began (e.g. drag started). |
| `interaction:update` | `(state) => void` | An active interaction updated (pointer moved). |
| `interaction:end` | `(state) => void` | An interaction ended (pointer released). |
| `command:before` | `(name, args) => void` | A command is about to execute. |
| `command:after` | `(name, args, duration) => void` | A command finished executing. |
| `command:blocked` | `(name, args) => void` | A command was blocked by middleware. |
| `invariant:failed` | `(failure) => void` | A state invariant was violated. |

## Plugins

### use

Installs a plugin at runtime. Plugins installed via `options.plugins` are equivalent.

```ts
use(plugin: BoardPlugin<R>): void
```

```ts
import { historyPlugin } from '@lupinum/board-history'
engine.use(historyPlugin())
```

### addMiddleware

Registers a command middleware that intercepts every command before execution. Call `next()` inside the middleware to allow the command to proceed; omit it to cancel. Returns an unsubscribe function.

```ts
addMiddleware(fn: CommandMiddleware): Unsubscribe
```

```ts
const unsub = engine.addMiddleware((name, args, next) => {
  if (name === 'deleteNode') return // block all deletes
  next()
})
```

### ext

The extension namespace populated by plugins. Each plugin calls `context.extend('key', value)` to register its API here.

```ts
readonly ext: BoardEngineExtensions<R>
```

```ts
// After installing connectionPlugin:
engine.ext.connections.createEdge({ from: nodeA, to: nodeB, data: {} })

// After installing historyPlugin:
engine.ext.history.undo()
```

## Group Utilities

### getUniformTranslationTargets

Returns the set of node IDs that should move together when the given seed nodes are dragged. Expands groups to include descendants and computes a coherent forest.

```ts
getUniformTranslationTargets(seedIds: NodeId[]): NodeId[]
```

### syncGroupZOrder

Ensures a group node and all its descendants have consistent z-ordering.

```ts
syncGroupZOrder(groupId: NodeId): void
```

## Import / Export

### exportJSON

Exports the full board state as a JSON string.

```ts
exportJSON(): string
```

```ts
const json = engine.exportJSON()
localStorage.setItem('board', json)
```

### importJSON

Imports board state from a JSON string. In `'replace'` mode (default), replaces all state. In `'merge'` mode, adds nodes to the existing board.

```ts
importJSON(json: string, mode?: 'replace' | 'merge'): void
```

```ts
const json = localStorage.getItem('board')
if (json) engine.importJSON(json, 'replace')
```

## Diagnostics

### exportTrace

Returns the event trace buffer. Each entry records an event name, timestamp, and arguments. The buffer is capped by `diagnostics.traceLimit` (default 500).

```ts
exportTrace(): TraceEntry[]
```

```ts
const trace = engine.exportTrace()
const lastEvent = trace[trace.length - 1]
console.log(lastEvent.event, lastEvent.timestamp)
```
