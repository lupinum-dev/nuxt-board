## connectionPlugin

Creates the connections plugin. Install it during engine creation or at runtime with `engine.use()`.

```ts
function connectionPlugin(options?: ConnectionPluginOptions): BoardPlugin
```

### Options

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `routing` | `ConnectionRouting` | `'bezier'` | Default edge routing style. |
| `defaultArrow` | `'none' \| 'start' \| 'end' \| 'both'` | `'none'` | Default arrowhead placement. |
| `snapDistance` | `number` | `undefined` | Snap distance for connection endpoints. |

```ts
import { createBoardEngine } from '@lupinum/board-core'
import { connectionPlugin } from '@lupinum/board-connections'

const engine = createBoardEngine({
  plugins: [connectionPlugin({ routing: 'bezier' })],
})
```

## Extension API

After installing the plugin, the connections API is available on `engine.ext.connections`.

### createEdge

Creates a new edge between two nodes. Returns the created edge.

```ts
createEdge<T>(input: {
  id?: EdgeId
  from: NodeId
  to: NodeId
  fromAnchor?: AnchorPosition
  toAnchor?: AnchorPosition
  data: T
  zIndex?: number
}): BoardEdge<T>
```

```ts
const edge = engine.ext.connections.createEdge({
  from: nodeA,
  to: nodeB,
  data: { label: 'depends on' },
})
```

### deleteEdge

Removes an edge by ID.

```ts
deleteEdge(id: EdgeId): void
```

### getEdges

Returns all edges.

```ts
getEdges(): BoardEdge[]
```

### getEdgesFrom

Returns all edges originating from a node.

```ts
getEdgesFrom(id: NodeId): BoardEdge[]
```

### getEdgesTo

Returns all edges pointing to a node.

```ts
getEdgesTo(id: NodeId): BoardEdge[]
```

### getEdgesBetween

Returns all edges between two specific nodes (in either direction).

```ts
getEdgesBetween(from: NodeId, to: NodeId): BoardEdge[]
```

## BoardConnectionLayer

A Vue component that renders edges as SVG paths inside the board viewport.

### Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `engine` | `BoardEngine \| null` | `null` | Engine instance. Falls back to `useBoardEngine()` context if omitted. |
| `routing` | `ConnectionRouting` | `'bezier'` | Routing style for all edges. |

### Slots

#### edge

Custom edge rendering. If not provided, edges render as SVG `<path>` elements.

| Prop | Type | Description |
| --- | --- | --- |
| `edge` | `BoardEdge` | The edge data. |
| `from` | `Point` | Resolved anchor point on the source node. |
| `to` | `Point` | Resolved anchor point on the target node. |
| `path` | `string` | SVG path string for the edge. |

```vue
<BoardConnectionLayer routing="step">
  <template #edge="{ edge, path }">
    <path :d="path" stroke="blue" stroke-width="2" fill="none" />
    <text>{{ edge.data.label }}</text>
  </template>
</BoardConnectionLayer>
```

### Usage

Place `BoardConnectionLayer` inside the `viewport` slot of `BoardRoot` so it renders in world-space:

```vue
<BoardRoot :engine="engine">
  <template #viewport>
    <BoardConnectionLayer />
  </template>
</BoardRoot>
```

## Utility Functions

### resolveAnchorPoint

Resolves an anchor position to a world-space point on a node. If no anchor is specified, returns the center of the node.

```ts
function resolveAnchorPoint(
  node: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>,
  anchor?: AnchorPosition,
): Point
```

### routeEdgePath

Generates an SVG path string between two points using the specified routing.

```ts
function routeEdgePath(from: Point, to: Point, routing?: ConnectionRouting): string
```

| Routing | Description |
| --- | --- |
| `'bezier'` | Smooth cubic bezier curve (default). |
| `'step'` | Right-angle stepped path. |
| `'straight'` | Direct straight line. |

### getEdgeBounds

Returns the bounding box of an edge between two points.

```ts
function getEdgeBounds(from: Point, to: Point): Bounds
```

### getVisibleEdges

Returns edges whose endpoints are within the given viewport bounds.

```ts
function getVisibleEdges(engine: BoardEngine, bounds: Bounds): BoardEdge[]
```

## Types

### BoardEdge

```ts
interface BoardEdge<T = Record<string, unknown>> {
  id: EdgeId
  from: NodeId
  to: NodeId
  fromAnchor?: AnchorPosition   // where the edge attaches on the source node
  toAnchor?: AnchorPosition     // where the edge attaches on the target node
  data: T                       // custom edge payload
  zIndex: number
}
```

### AnchorPosition

```ts
interface AnchorPosition {
  side: AnchorSide     // 'top' | 'right' | 'bottom' | 'left'
  offset: number       // 0–1 position along the side (0.5 = center)
}
```

### AnchorSide

```ts
type AnchorSide = 'top' | 'right' | 'bottom' | 'left'
```

### ConnectionRouting

```ts
type ConnectionRouting = 'bezier' | 'step' | 'straight'
```

## Events

The connections plugin adds these events to `BoardEventMap`:

| Event | Handler | Description |
| --- | --- | --- |
| `edge:created` | `(edge: BoardEdge) => void` | An edge was created. |
| `edge:deleted` | `(edgeId: EdgeId) => void` | An edge was removed. |

```ts
engine.on('edge:created', (edge) => {
  console.log('New edge:', edge.from, '->', edge.to)
})
```

Edges are automatically deleted when either endpoint node is deleted.
