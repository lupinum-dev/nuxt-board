This cookbook page builds an auto-save plugin from scratch. It is not a feature tour. It is the implementation walkthrough.

::steps{level="3"}

### Define the plugin

```ts
function autoSavePlugin(options: {
  key: string
  debounceMs?: number
}): BoardPlugin {
  return {
    name: 'auto-save',
    install(ctx) {
      // setup
    },
  }
}
```

### Listen for changes and debounce

```ts
ctx.on('command:after', (name) => {
  if (name.startsWith('zoom') || name.startsWith('pan')) return
  scheduleSave()
})
```

### Serialize and persist

```ts
function save() {
  const json = ctx.exportJSON()
  localStorage.setItem(options.key, json)
}
```
