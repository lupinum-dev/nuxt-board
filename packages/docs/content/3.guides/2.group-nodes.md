Groups are nodes that contain other nodes. When you move a group, its children follow. They are structural containers — transparent by default — that give your board hierarchy.

---

## Creating a Group

```ts
const group = engine.createNode({
  type: 'group',
  x: 50,
  y: 50,
  width: 500,
  height: 400,
  data: { title: 'Sprint 1', accent: '#ea580c' },
})
```

---

## Assigning Children

Set `parentId` on a node to make it a child of a group:

```ts
// During creation
engine.createNode({
  type: 'text',
  x: 80,
  y: 100,
  data: { content: 'Task A' },
  parentId: group.id,
})

// Or update an existing node
engine.updateNode(childId, { parentId: group.id })
```

---

## Wrapping Selection in a Group

A common pattern — wrap the current selection into a new group:

```ts
import { getSelectionNodes, getSelectionBounds } from '@lupinum/board-selection'

function wrapSelectionInGroup(engine) {
  const selected = getSelectionNodes(engine)
  if (selected.length === 0) return

  const bounds = getSelectionBounds(engine)
  if (!bounds) return

  const padding = 24
  const group = engine.createNode({
    type: 'group',
    x: bounds.minX - padding,
    y: bounds.minY - padding,
    width: bounds.maxX - bounds.minX + padding * 2,
    height: bounds.maxY - bounds.minY + padding * 2,
    data: { title: 'Group', accent: '#3b82f6' },
  })

  // Reparent all selected nodes into the group
  for (const node of selected) {
    engine.updateNode(node.id, { parentId: group.id })
  }

  // Ensure proper z-ordering
  engine.sendToBack(group.id)
  engine.syncGroupZOrder(group.id)
  engine.select(group.id)
}
```

## Drag Propagation

When you drag a group, the engine automatically moves all descendants. The `getUniformTranslationTargets()` method computes the coherent set of nodes that move together:

```ts
const targets = engine.getUniformTranslationTargets([groupId])
// Returns: [groupId, child1, child2, nestedGroup, nestedChild, ...]
```

This handles nested groups correctly — each node appears exactly once.

---

## Z-order management

::warning
Groups must render behind their children. Always call `syncGroupZOrder()` after modifying a group hierarchy.
::

```ts
engine.sendToBack(groupId)
engine.syncGroupZOrder(groupId)
```

::collapsible

### Hierarchy utility functions

These functions from `@lupinum/board-core` help navigate the node hierarchy:

```ts
import {
  addDescendants,
  collectSubtreeIds,
  isStrictDescendantOf,
  findContainingGroup,
} from '@lupinum/board-core'

// Get all descendants of a group
const descendants = new Set<NodeId>()
addDescendants(groupId, engine.getState().nodes, descendants)

// Check if a node is inside a group (at any depth)
isStrictDescendantOf(nodeId, groupId, engine.getState().nodes)

// Find which group contains a node based on its center point
const containingGroupId = findContainingGroup(node, engine.getState().nodes)
```

::

## Custom Group Renderer

Groups render with no background or border by default (`.board-node.is-group` removes them). Register a custom renderer for richer visuals:

```vue
<!-- MyGroupRenderer.vue -->
<script setup lang="ts">
import type { BoardNode } from '@lupinum/board-core'

const props = defineProps<{
  node: BoardNode
  selected: boolean
}>()
</script>

<template>
  <div class="group-header" :style="{ borderColor: node.data.accent }">
    <span class="group-title">{{ node.data.title }}</span>
  </div>
</template>

<style scoped>
.group-header {
  border-top: 3px solid;
  padding: 8px 12px;
  font-weight: 600;
  font-size: 0.875rem;
  text-transform: uppercase;
  letter-spacing: 0.05em;
}
</style>
```

```ts
const renderers = { group: MyGroupRenderer }
```
