Save and load boards as JSON. Use engine snapshots for app-local persistence and JSON Canvas when you need an interoperable document shape.

::serializer-board-demo
::

## Quick export/import

The engine has built-in JSON export/import that uses snapshots:

```ts
// Export
const json = engine.exportJSON()
localStorage.setItem('board', json)

// Import
const stored = localStorage.getItem('board')
if (stored) {
  engine.importJSON(stored, 'replace')
}
```

---

## Using the Serializer

For JSON Canvas format compliance and custom type handling, use `@lupinum/board-serializer`:

```ts
import { jsonCanvasSerializer } from '@lupinum/board-serializer'

// Export to JSON Canvas format
const json = jsonCanvasSerializer.export(engine)

// Parse a JSON Canvas document
const document = jsonCanvasSerializer.parse(json)

// Rebuild the engine, including connection edges
jsonCanvasSerializer.hydrateEngine(engine, document, 'replace')
```

### Including edges

```ts
const edges = engine.ext.connections.getEdges()
const json = jsonCanvasSerializer.export(engine, { edges })
```

### Node colors

Node colors are exported as top-level JSON Canvas node `color` fields:

```json
{
  "id": "card-1",
  "type": "text",
  "x": 80,
  "y": 80,
  "width": 260,
  "height": 140,
  "color": "5",
  "text": "Draft release notes"
}
```

Import reads valid preset IDs into `BoardNode.color`. Edge colors remain separate connection data.

## Custom Type Handlers

Register handlers to control how specific node types are serialized:

```ts
jsonCanvasSerializer.registerType('image', {
  serialize: (node) => ({
    src: node.data.src,
    alt: node.data.alt,
  }),
  deserialize: (raw) => ({
    src: raw.src as string,
    alt: raw.alt as string,
  }),
})
```

Without a handler, the default behavior stores `data.content` as the `text` field.

## The x-canvas extension

Board-specific metadata that has no JSON Canvas top-level field is stored under `x-canvas`. That includes camera, grid, z-order, lock state, visibility, and hierarchy.

::collapsible

### x-canvas JSON structure

```json
{
  "nodes": [...],
  "edges": [...],
  "x-canvas": {
    "camera": { "x": 0, "y": 0, "z": 1 },
    "grid": { "size": 20, "majorEvery": 5, "snap": true, "pattern": "line" },
    "nextZIndex": 5,
    "nodes": {
      "node-1": { "zIndex": 1, "locked": false, "visible": true },
      "node-2": { "zIndex": 2, "parentId": "group-1" }
    }
  }
}
```

## Import Modes

```ts
// Replace all state
engine.importJSON(json, 'replace')

// Merge into existing board
engine.importJSON(json, 'merge')
```
