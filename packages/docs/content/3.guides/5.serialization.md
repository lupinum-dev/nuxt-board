Save and load boards as JSON Canvas documents. Runtime snapshots are for rendering and tests; persisted documents go through `engine.exportJSON()` and `engine.importJSON()`.

::json-import-export-demo
::

## Quick export/import

The engine exports the canonical persisted document shape:

```ts
// Export
const json = engine.exportJSON()
localStorage.setItem('board', json)

// Import
const stored = localStorage.getItem('board')
if (stored) {
  engine.importJSON(stored, 'replace')
}
```

## Connections

```ts
const engine = createBoardEngine({
  plugins: [connectionPlugin()],
})

const json = engine.exportJSON()
engine.importJSON(json, 'replace')
```

When the connections plugin is installed, it owns edge export and import. Core validates the JSON Canvas document and passes plugin-owned fields to installed plugins; core does not persist hidden connection state by itself.

### Node colors

Node colors are exported as top-level JSON Canvas node `color` fields:

```json
{
  "id": "card-1",
  "type": "text",
  "x": 80,
  "y": 80,
  "width": 260,
  "height": 140,
  "color": "5",
  "text": "Draft release notes"
}
```

Import reads valid preset IDs into `BoardNode.color`. Edge colors remain separate connection data.

## The x-nuxt-board extension

Board-specific metadata that has no JSON Canvas top-level field is stored under `x-nuxt-board`. That includes camera, grid, z-order, lock state, visibility, hierarchy, and plugin-owned metadata.

::collapsible

### Document structure

```json
{
  "nodes": [...],
  "edges": [...],
  "x-nuxt-board": {
    "camera": { "x": 0, "y": 0, "z": 1 },
    "grid": { "size": 20, "majorEvery": 5, "snap": true, "pattern": "line" },
    "nextZIndex": 5,
    "nodes": {
      "node-1": { "zIndex": 1, "locked": false, "visible": true },
      "node-2": { "zIndex": 2, "parentId": "group-1" }
    }
  }
}
```

## Import Modes

```ts
// Replace all state
engine.importJSON(json, 'replace')

// Merge into existing board
engine.importJSON(json, 'merge')
```
