Install `@lupinum/board-core` with the renderer or integration package your app uses.

## Vue

For a Vue 3 app, install the headless engine and Vue renderer:

```bash
pnpm add @lupinum/board-core @lupinum/vue-board
```

The same package set works with npm or yarn:

::tabs

:::tabs-item{label="npm" icon="i-lucide-terminal"}

```bash
npm install @lupinum/board-core @lupinum/vue-board
```

:::

:::tabs-item{label="yarn" icon="i-lucide-terminal"}

```bash
yarn add @lupinum/board-core @lupinum/vue-board
```

:::

::

Import the renderer stylesheet once in your app entry:

```ts [main.ts]
import '@lupinum/vue-board/style.css'
```

## Nuxt

For Nuxt, install the module:

```bash
pnpm add nuxt-board @lupinum/board-core @lupinum/vue-board
```

Register it in `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-board'],
})
```

The module auto-imports the board components, composables, and `createBoardEngine()`. You can still import from `@lupinum/board-core` directly when you want explicit engine types or helpers such as `asNodeId()`.

## Optional Packages

Install plugins only when the board needs the behavior.

| Task                       | Package                      |
| -------------------------- | ---------------------------- |
| Draw edges between nodes   | `@lupinum/board-connections` |
| Add undo and redo          | `@lupinum/board-history`     |
| Render a minimap           | `@lupinum/vue-board/minimap` |
| Work with selection bounds | `@lupinum/board-core`        |

Example:

```bash
pnpm add @lupinum/board-connections @lupinum/board-history
```

## Verify the Install

Create an engine and read the initial camera:

```ts
import { createBoardEngine } from '@lupinum/board-core'

const engine = createBoardEngine()

console.log(engine.getState().camera.z)
```

The value should be `1`.

## Common Setup Checks

If the first board does not render, check these before changing code structure:

| Symptom                                      | Check                                                                                                                               |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| The board area is blank or collapsed         | Give `BoardRoot` an explicit height, such as `style="height: 100vh"`.                                                               |
| The board is unstyled in Vue                 | Import `@lupinum/vue-board/style.css` once in your app entry.                                                                       |
| The board is unstyled in Nuxt                | Make sure `nuxt-board` is registered; the module adds the stylesheet for you.                                                       |
| `createBoardEngine` is not available in Nuxt | Keep `autoImportComposables` enabled, or import it from `@lupinum/board-core` explicitly.                                           |
| A composable cannot find the board engine    | Call board composables inside a component rendered under `BoardRoot`.                                                               |
| Connections render nothing                   | Install `@lupinum/board-connections`, pass `connectionsPlugin()` to `plugins`, and render `BoardConnectionLayer` under `BoardRoot`. |
