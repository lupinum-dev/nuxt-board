By the end of this page, you will render a board with one draggable, resizable, editable card.

::tip
Store the engine in `shallowRef(engine)` if it needs to live in Vue state. Do not wrap the engine in `reactive()`.
::

## Prerequisites

Install the packages first:

::tabs

:::tabs-item{label="Vue" icon="i-lucide-file-code"}

```bash
pnpm add @lupinum/board-core @lupinum/vue-board
```

:::

:::tabs-item{label="Nuxt" icon="i-lucide-boxes"}

```bash
pnpm add nuxt-board @lupinum/board-core @lupinum/vue-board
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-board'],
})
```

:::

::

## Create the Engine

The engine is the source of truth for board state:

```ts
import { createBoardEngine } from '@lupinum/board-core'

const engine = createBoardEngine({
  grid: { size: 20, snap: true },
})
```

Grid snapping is optional, but it gives the first board predictable movement.

## Add One Card

Create a node before mounting the board:

```ts
engine.createNode({
  type: 'text',
  x: 80,
  y: 80,
  width: 260,
  height: 140,
  color: '5',
  text: 'Node',
})
```

The `type` is one of the JSON Canvas node types. For text nodes, `text` is what the default renderer shows. `color` accepts the built-in preset IDs or a six-digit hex color.

## Mount the Board

Use `BoardRoot` to render the board shell:

::tabs

:::tabs-item{label="Vue" icon="i-lucide-file-code"}

```vue [App.vue]
<script setup lang="ts">
import { createBoardEngine } from '@lupinum/board-core'
import { BoardRoot } from '@lupinum/vue-board'
import '@lupinum/vue-board/style.css'

const engine = createBoardEngine({
  grid: { size: 20, snap: true },
})

engine.createNode({
  type: 'text',
  x: 80,
  y: 80,
  width: 260,
  height: 140,
  color: '5',
  text: 'Node',
})
</script>

<template>
  <BoardRoot :engine="engine" style="height: 100vh" />
</template>
```

:::

:::tabs-item{label="Nuxt" icon="i-lucide-boxes"}

```vue [app.vue]
<script setup lang="ts">
import { asNodeId } from '@lupinum/board-core'

const engine = createBoardEngine({
  grid: { size: 20, snap: true },
})

engine.createNode({
  id: asNodeId('hello-board'),
  type: 'text',
  x: 80,
  y: 80,
  width: 260,
  height: 140,
  color: '5',
  text: 'Node',
})
</script>

<template>
  <BoardRoot :engine="engine" style="height: 100vh" />
</template>
```

:::

::

The Nuxt example passes a stable `id` so server and client rendering produce the same first node. In client-only Vue apps, you can omit `id` and let the engine create one.

## Check the Interaction Model

Try these actions on the board:

- Drag a card to move it.
- Resize from a corner handle.
- Double-click a card to edit text.
- Select a node and use the floating toolbar to remove, color, zoom to, or edit it.
- :kbd{value="Delete"} or :kbd{value="Backspace"} deletes the selection.
- :kbd{value="meta"} + scroll zooms the camera.

## What Happened

`createBoardEngine()` created the headless model. `createNode()` added the first record through a guarded command. `BoardRoot` subscribed to the engine and rendered the viewport, grid, nodes, handles, selection toolbar, and pointer interactions.
