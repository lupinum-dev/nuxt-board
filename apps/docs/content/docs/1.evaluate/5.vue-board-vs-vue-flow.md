Vue Board and Vue Flow both build interactive node interfaces in Vue. They start from different centers of gravity.

> Comparison reviewed against the Vue Flow documentation on 2026-07-14. Verify current APIs before migrating production code.

| Question            | Vue Board                                              | Vue Flow                                                |
| ------------------- | ------------------------------------------------------ | ------------------------------------------------------- |
| Primary abstraction | Headless board document and command engine             | Interactive flow-graph component                        |
| Canonical mutation  | Engine commands and atomic batches                     | Node and edge changes through the flow model            |
| Node model          | JSON Canvas records with custom presentation           | Graph nodes associated with node components and handles |
| Edges               | Optional first-party package and document extension    | Central graph concept                                   |
| Persistence         | Validated JSON Canvas import/export                    | Application serializes the graph state it owns          |
| History             | Optional commit-root history plugin                    | Application or ecosystem integration                    |
| Framework boundary  | Core is framework-agnostic                             | Vue is central to the model and rendering surface       |
| Best fit            | Spatial product documents and explicit mutation policy | Flowcharts and node-edge editors centered on the graph  |

## Choose Vue Board when

You want a board document outside Vue, one guarded mutation path, explicit transaction failure, or JSON Canvas persistence. It also fits when connections are optional rather than the definition of the document.

## Choose Vue Flow when

The product is fundamentally a connected graph, handles and edges are central, or you want the established React Flow-style component model in Vue. Vue Flow has a broader graph-focused ecosystem and a longer public track record.

## Equivalent intent

In Vue Board, application code calls `engine.createNode()` and installs the connections plugin for edges. In Vue Flow, application state supplies nodes and edges to the flow component. The visible result can match; ownership and lifecycle differ.

Sources: [Vue Flow documentation](https://vueflow.dev/) and [Vue Board architecture](https://github.com/lupinum/nuxt-board/blob/main/ARCHITECTURE.md).
