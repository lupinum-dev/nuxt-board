Vue and Nuxt use the same engine. Only component, composable, and style registration differs.

## Vue

Import `BoardRoot`, composables, and styles explicitly. This keeps dependencies visible and works in any Vue 3 build.

## Nuxt

Add `nuxt-board` to `modules`. The defaults register board components, composables, styles, and transpilation support. Prefix auto-imported names when the application has collisions.

## SSR

Use deterministic IDs and complete initial records. Do not create random initial nodes during hydration. Browser-only measurements remain session state and are populated after mount.

The Nuxt module does not wrap the engine or create a second store. The same persistence, command, and plugin rules apply in both environments.
