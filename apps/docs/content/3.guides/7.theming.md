Theme the board with CSS variables. Keep semantic state, such as node color presets, in engine state.

::theme-playground
::

## Core tokens

::field-group
::field{name="--board-bg" type="color" default="#fff"}
Board background.
::

::field{name="--board-fg" type="color" default="#0f172a"}
Text, grid contrast, and general foreground color.
::

::field{name="--board-node-bg" type="color" default="#fff"}
Default node surface.
::

::field{name="--board-node-border" type="color" default="rgba(15, 23, 42, 0.15)"}
Default node border color.
::

::field{name="--board-accent" type="color" default="#3b82f6"}
Selection accents and snap guides.
::

::field{name="--board-node-color" type="color" default="unset"}
Resolved border color for a colored node. Usually set by the renderer from `node.color`.
::

::field{name="--board-node-tint" type="color" default="unset"}
Subtle surface tint for colored cards and groups.
::

::field{name="--board-node-color-ring" type="color" default="unset"}
Selection outline color for a colored node.
::

::field{name="--board-snap-guide-color" type="color" default="rgba(15, 118, 110, 0.95)"}
Snap guide line color.
::

::field{name="--board-snap-guide-width" type="length" default="2px"}
Snap guide line thickness.
::

::field{name="--board-snap-guide-glow-size" type="length" default="18px"}
Snap guide glow radius. Set to `0` to disable the glow effect.
::
::

## Light and dark examples

::tabs

:::tabs-item{label="Light" icon="i-lucide-sun"}

```css
.board-root {
  --board-bg: #f8fafc;
  --board-fg: #0f172a;
  --board-node-bg: #ffffff;
  --board-node-border: rgba(15, 23, 42, 0.14);
  --board-accent: #0ea5e9;
}
```

## Node Color Presets

Node colors are stored as preset IDs:

```ts
engine.updateNode(card.id, { color: '5' })
engine.updateNode(card.id, { color: undefined })
```

The built-in renderer resolves those presets into `--board-node-color`, `--board-node-tint`, `--board-node-color-soft`, and `--board-node-color-ring`. Use those variables in custom renderers instead of reading preset IDs directly in CSS.

```css
.task-card {
  border-color: var(--board-node-color, var(--board-node-border));
  background: var(--board-node-tint, var(--board-node-bg));
}
```

The selection toolbar can batch-apply the same preset to selected cards and groups.

::collapsible

### Styling specific states

```css
.board-node.is-selected {
  outline: calc(3px / var(--board-zoom, 1)) solid var(--board-accent);
}

.board-node.is-locked {
  opacity: 0.72;
}

.board-node.is-group {
  background: var(--board-node-tint, var(--board-group-bg));
}
```

Use state classes when you want a special selected, locked, or group look without replacing the full renderer.
