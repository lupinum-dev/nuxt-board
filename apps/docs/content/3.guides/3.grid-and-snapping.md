The grid gives the board structure. It controls both the pattern you see and whether node operations lock into alignment.

::grid-pattern-demo
::

## Setting up the grid

Pass grid options when you create the engine:

```ts
const engine = createBoardEngine({
  grid: {
    size: 20,
    snap: true,
    pattern: 'line',
  },
})
```

::tip
You can change grid settings at runtime with `engine.updateGridSettings({ pattern: 'dot' })`. The board updates immediately.
::

## Grid options

::field-group
::field{name="size" type="number" default="20"}
Cell size in world units.
::

::field{name="snap" type="boolean" default="true"}
Whether create, move, resize, and arrow-key nudge operations align to the grid.
::

::field{name="edgeSnap" type="boolean" default="true"}
Whether dragging and resizing snaps to nearby node edges and shows alignment guides. Independent of grid snapping.
::

::field{name="edgeSnapThreshold" type="number" default="8"}
How close (in screen pixels) a node edge must be before it snaps. Lower values require more precision; higher values snap more eagerly.
::

::field{name="pattern" type="'line' | 'dot' | 'cross' | 'none'" default="'line'"}
The visual grid pattern. Compare the boards above to feel the difference.
::

::field{name="majorEvery" type="number" default="5"}
Every Nth line renders as a stronger guide.
::
::

## Snap behavior

::snap-demo
::

When `snap` is enabled, these operations align to the grid: creating nodes, moving nodes, resizing nodes, and arrow-key nudging.

When `edgeSnap` is enabled, the engine also checks nearby node edges and shows alignment guides when things line up. Both modes are independent — you can use grid snapping without edge guides, or edge guides without grid snapping.

::note
Set `edgeSnap: false` to disable alignment guides, or adjust `edgeSnapThreshold` to control how eagerly nodes snap to each other. Hold **Space** while dragging to temporarily bypass all snapping.
::

::collapsible

### Visual fine-tuning

```vue
<BoardRoot
  :engine="engine"
  :grid="{
    visible: true,
    minorOpacity: 0.14,
    majorOpacity: 0.18,
    fadeEdges: true,
  }"
/>
```

Minor lines fade as zoom drops, so the board does not turn into noise when you zoom far out.
::
