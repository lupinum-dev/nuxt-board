Releases use Changesets. User-visible package changes need a changeset so versioning and release notes stay connected to the change.

## Add a Changeset

Run this from the repository root:

```bash
pnpm changeset
```

Choose the affected packages and version bump. Describe user impact, not internal implementation detail.

Good entry:

> Add node color presets and JSON Canvas color export.

Weak entry:

> Update engine types.

## Validate Before Merge

Run the checks that match the change:

```bash
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test:unit
pnpm test:docs
pnpm pack:check
pnpm test:e2e
pnpm audit --prod --audit-level high
```

## Publish Flow

Merges to `main` create or update the Changesets version PR. When that PR is merged, the release workflow publishes the public packages to npm.

## Docs Deployment

`.github/workflows/docs.yml` deploys preview docs for pull requests and production docs from `main` when the Vercel secrets are configured.

Set `NUXT_PUBLIC_SITE_URL` for production so canonical URLs and social metadata point to the deployed docs site.
