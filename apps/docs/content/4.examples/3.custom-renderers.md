## What’s happening

This example renders supported JSON Canvas node types with custom Vue components. The board shell still handles interaction, selection, and layout. Only the node content changes.

## The code

::code-tree{defaultValue="app.vue"}

```ts [app.vue]
import DocsInsightNode from './DocsInsightNode.vue'
import DocsMetricNode from './DocsMetricNode.vue'

const renderers = {
  text: DocsInsightNode,
  group: DocsMetricNode,
}
```

```vue [template.vue]
<BoardRoot :engine="engine" :renderers="renderers" style="height: 100vh" />
```

::

## Try these things

- Add an insight text node and a metric group node.
- Compare them with the default text node on the same board.
- Resize all three types and notice the interaction model stays the same.
