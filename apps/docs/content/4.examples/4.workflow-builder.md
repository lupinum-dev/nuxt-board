## What’s happening

This example combines three patterns: a custom renderer for step-style cards, the connections plugin for flow lines, and the history plugin for undo and redo. The step fields are encoded in `node.text` only to keep this demo focused on rendering; production workflow state should have one source of truth, usually an app-owned workflow model that derives the board nodes it needs.

## The code

::code-tree{defaultValue="app.vue"}

```vue [app.vue]
<script setup lang="ts">
import { createBoardEngine } from '@lupinum/board-core'
import { historyPlugin } from '@lupinum/board-history'
import {
  connectionPlugin,
  BoardConnectionLayer,
} from '@lupinum/board-connections'
import StepNode from './StepNode.vue'

const engine = createBoardEngine({
  extensions: [historyPlugin(), connectionPlugin({ routing: 'step' })],
})
</script>

<template>
  <BoardRoot
    :engine="engine"
    :renderers="{ text: StepNode }"
    style="height: 100vh"
  >
    <BoardConnectionLayer routing="step" />
  </BoardRoot>
</template>
```

```vue [StepNode.vue]
<template>
  <div class="step-card">
    <span>{{ node.text?.split('\n')[0] }}</span>
    <strong>{{ node.text?.split('\n')[1] }}</strong>
  </div>
</template>
```

::

## Try these things

- Select a step, then click **Cycle selected step** to advance its status.
- Drag a step — the routed edges redraw to stay readable.
- Press :kbd{value="meta"}+:kbd{value="Z"} to undo, then :kbd{value="meta"}+:kbd{value="shift"}+:kbd{value="Z"} to redo.
- Watch the undo/redo counter in the toolbar update in real time.
