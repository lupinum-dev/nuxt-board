These utility functions are exported from `@lupinum/board-core`. They are pure functions — they do not mutate state and can be used outside the engine for custom calculations.

## General Math

### clamp

Constrains a value to a range.

```ts
clamp(value: number, min: number, max: number): number
```

```ts
clamp(15, 0, 10) // 10
clamp(-5, 0, 10) // 0
```

### lerp

Linear interpolation between two values.

```ts
lerp(a: number, b: number, t: number): number
```

```ts
lerp(0, 100, 0.5) // 50
```

### lerpCamera

Interpolates between two camera states. Useful for animated transitions.

```ts
lerpCamera(from: Camera, to: Camera, t: number): Camera
```

```ts
const mid = lerpCamera({ x: 0, y: 0, z: 1 }, { x: 100, y: 50, z: 2 }, 0.5)
// { x: 50, y: 25, z: 1.5 }
```

## Coordinate Conversion

### screenToWorld

Converts a screen-space point to world-space coordinates given a camera.

```ts
screenToWorld(point: Point, camera: Camera): Point
```

```ts
const world = screenToWorld({ x: 640, y: 360 }, { x: 0, y: 0, z: 1 })
```

### worldToScreen

Converts a world-space point to screen-space coordinates.

```ts
worldToScreen(point: Point, camera: Camera): Point
```

### getVisibleBounds

Returns the world-space bounds visible within a viewport of the given size.

```ts
getVisibleBounds(width: number, height: number, camera: Camera): Bounds
```

```ts
const bounds = getVisibleBounds(1280, 720, camera)
```

### zoomCameraAtScreenPoint

Computes a new camera state after zooming at a specific screen point. The zoom remains centered on the cursor.

```ts
zoomCameraAtScreenPoint(
  screenPoint: Point,
  delta: number,
  camera: Camera,
  min: number,
  max: number,
): Camera
```

## Bounds Logic

### pointInBounds

Returns `true` if a point is inside the given bounds (inclusive).

```ts
pointInBounds(point: Point, bounds: Bounds): boolean
```

### boundsIntersect

Returns `true` if two bounds overlap.

```ts
boundsIntersect(a: Bounds, b: Bounds): boolean
```

### boundsContain

Returns `true` if the outer bounds fully contain the inner bounds.

```ts
boundsContain(outer: Bounds, inner: Bounds): boolean
```

### getBoundsFromPoints

Creates a `Bounds` from two arbitrary points (min/max are computed automatically).

```ts
getBoundsFromPoints(a: Point, b: Point): Bounds
```

```ts
const bounds = getBoundsFromPoints({ x: 10, y: 20 }, { x: 50, y: 5 })
// { minX: 10, minY: 5, maxX: 50, maxY: 20 }
```

## Grid Snapping

### snapValue

Rounds a value to the nearest grid step. Returns the original value if `step <= 0`.

```ts
snapValue(value: number, step: number): number
```

```ts
snapValue(37, 10) // 40
snapValue(12, 10) // 10
```

### snapPoint

Snaps both coordinates of a point to a grid step.

```ts
snapPoint(point: Point, step: number): Point
```

### snapBounds

Snaps all four edges of a bounds to a grid step.

```ts
snapBounds(bounds: Bounds, step: number): Bounds
```

### snapSize

Snaps a size value to a grid step, enforcing a minimum.

```ts
snapSize(value: number, step: number, min: number): number
```

```ts
snapSize(87, 20, 50) // 80
snapSize(30, 20, 50) // 50 (minimum enforced)
```

## Hierarchy Utilities

### getBoundsFromNode

Converts a node's position and size to a `Bounds` object.

```ts
getBoundsFromNode(node: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>): Bounds
```

```ts
const bounds = getBoundsFromNode(node)
// { minX: node.x, minY: node.y, maxX: node.x + node.width, maxY: node.y + node.height }
```

### groupArea

Returns the area of a node (width × height). Useful for sorting groups by size.

```ts
groupArea(node: BoardNode): number
```

### addDescendants

Recursively adds all descendant IDs of a group node into the `out` set.

```ts
addDescendants(rootId: NodeId, nodes: Map<NodeId, BoardNode>, out: Set<NodeId>): void
```

```ts
const descendants = new Set<NodeId>()
addDescendants(groupId, state.nodes, descendants)
```

### expandGroupDragSeeds

Expands a set of seed IDs by adding all descendants of any group nodes in the set.

```ts
expandGroupDragSeeds(seedIds: Iterable<NodeId>, nodes: Map<NodeId, BoardNode>): Set<NodeId>
```

### collectSubtreeIds

Recursively collects all IDs in a subtree rooted at the given node (inclusive).

```ts
collectSubtreeIds(rootId: NodeId, nodes: Map<NodeId, BoardNode>, into: Set<NodeId>): void
```

### collectUniformTranslationTargets

Computes the full set of node IDs that should move together when the given seeds are dragged. Handles nested groups correctly — each node appears exactly once.

```ts
collectUniformTranslationTargets(seedIds: Iterable<NodeId>, nodes: Map<NodeId, BoardNode>): NodeId[]
```

### isStrictDescendantOf

Returns `true` if `maybeDescendant` is nested (at any depth) inside `ancestorId`.

```ts
isStrictDescendantOf(maybeDescendant: NodeId, ancestorId: NodeId, nodes: Map<NodeId, BoardNode>): boolean
```

### findContainingGroup

Finds the smallest visible group whose bounds contain the center of the given node. Returns `undefined` if no group contains it.

```ts
findContainingGroup(node: BoardNode, nodes: Map<NodeId, BoardNode>): NodeId | undefined
```

### sortIdsByZIndex

Sorts node IDs by their z-index (ascending).

```ts
sortIdsByZIndex(ids: NodeId[], nodes: Map<NodeId, BoardNode>): NodeId[]
```

## Edge Snapping

These functions power the snap-to-edge alignment guides during drag and resize.

### collectNodeEdges

Returns the four edges (left, right, top, bottom) of a node as snap candidates.

```ts
collectNodeEdges(node: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>): EdgeCandidate[]
```

### snapPositionToEdges

Snaps a node's position to nearby edges of other nodes. Returns the adjusted delta and any snap guides to display.

```ts
snapPositionToEdges(
  bounds: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>,
  otherEdges: EdgeCandidate[],
  threshold: number,
): DragSnapResult
```

```ts
const otherEdges = collectNodeEdges(otherNode)
const result = snapPositionToEdges(draggedNode, otherEdges, 8)
// result.dx, result.dy — adjusted position deltas
// result.guides — snap guides to render
```

### snapBoundsToEdges

Snaps the resizing edges of a bounds to nearby node edges. Used during resize operations.

```ts
snapBoundsToEdges(
  bounds: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>,
  handle: ResizeHandle,
  otherEdges: EdgeCandidate[],
  threshold: number,
): SnapResult
```

## Resize Utilities

### applyResizeDelta

Applies a resize delta to node bounds, respecting constraints. Returns the new bounds.

```ts
applyResizeDelta(
  node: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>,
  handle: ResizeHandle,
  deltaX: number,
  deltaY: number,
  constraints: ResizeConstraints,
): Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>
```

### applyResizeDeltaLocked

Aspect-ratio-locked variant. For corner handles, the dominant axis drives the resize. For edge handles, the active axis drives and the perpendicular axis is derived.

```ts
applyResizeDeltaLocked(
  node: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>,
  handle: ResizeHandle,
  deltaX: number,
  deltaY: number,
  constraints: ResizeConstraints,
  aspectRatio: number,
): Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>
```

### snapResizedBounds

Snaps resized bounds to the grid, respecting min size constraints.

```ts
snapResizedBounds(
  bounds: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>,
  handle: ResizeHandle,
  gridSize: number,
  constraints: ResizeConstraints,
): Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>
```

### snapResizedBoundsLocked

Aspect-ratio-preserving grid snap. Snaps the primary dimension and derives the secondary from the ratio.

```ts
snapResizedBoundsLocked(
  bounds: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>,
  startBounds: Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>,
  handle: ResizeHandle,
  gridSize: number,
  constraints: ResizeConstraints,
  aspectRatio: number,
): Pick<BoardNode, 'x' | 'y' | 'width' | 'height'>
```
