These utility functions are exported from `@lupinum/board-core`. They are pure functions and can be used outside the engine for custom calculations.

The engine also exposes instance methods such as `engine.screenToWorld()` and `engine.worldToScreen()` when the calculation depends on the current board camera.

## General Math

### clamp

Constrains a value to a range.

```ts
clamp(value: number, min: number, max: number): number
```

```ts
clamp(15, 0, 10) // 10
clamp(-5, 0, 10) // 0
```

## Bounds Logic

### boundsIntersect

Returns `true` if two bounds overlap.

```ts
boundsIntersect(a: Bounds, b: Bounds): boolean
```

### getBoundsFromPoints

Creates a `Bounds` from two arbitrary points. Minimum and maximum corners are computed automatically.

```ts
getBoundsFromPoints(a: Point, b: Point): Bounds
```

```ts
const bounds = getBoundsFromPoints({ x: 10, y: 20 }, { x: 50, y: 5 })
// { minX: 10, minY: 5, maxX: 50, maxY: 20 }
```

### getVisibleBounds

Returns the world-space bounds visible within a viewport for the given camera.

```ts
getVisibleBounds(width: number, height: number, camera: Camera): Bounds
```

```ts
const bounds = getVisibleBounds(1280, 720, camera)
```
