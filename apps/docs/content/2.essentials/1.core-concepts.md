This page is the map, not the full hike. Read the short version here, then jump to the deeper page when a concept becomes relevant.

::tabs

:::tabs-item{label="Engine" icon="i-lucide-box"}

```ts
const engine = createBoardEngine({
  grid: { size: 20, snap: true },
})
```

The engine is the source of truth. It owns nodes, camera state, selection, interaction state, commands, and events.

::tip
Think “mutable board model with guarded commands,” not “Vue component with hidden state.”
::

[Learn more → Quick Start](/getting-started/quick-start)
:::

:::tabs-item{label="Nodes" icon="i-lucide-square"}

```ts
engine.createNode({
  type: 'text',
  x: 80,
  y: 80,
  text: 'Node',
})
```

Nodes are immutable records. Geometry, hierarchy, visibility, and data all live on the node itself.

::note
The node `type` is just a string until you give it meaning with renderers, first-party packages, or your own app logic.
::

[Learn more → Working with Nodes](/essentials/nodes)
:::

:::tabs-item{label="Commands" icon="i-lucide-terminal"}

```ts
engine.updateNode(node.id, {
  text: 'Node',
})
```

Every mutation goes through a command. That keeps command guards, history, events, and validation in one place.

::tip
If something changes state, prefer a command over mutating around the engine.
::

[Learn more → First-party Features and Command Guards](/guides/extensions-and-middleware)
:::

:::tabs-item{label="Rendering" icon="i-lucide-layout-template"}

```vue
<BoardRoot :engine="engine" :renderers="renderers" />
```

`BoardRoot` handles viewport math, pointer interaction, selection visuals, and default rendering. Your custom renderer only draws node content.

::tip
Custom renderers replace presentation, not interaction. Dragging, resizing, and selection still come from the board shell.
::

[Learn more → Custom Renderers](/essentials/renderers)
:::

:::tabs-item{label="First-party features" icon="i-lucide-puzzle"}

```ts
const engine = createBoardEngine({
  extensions: [historyPlugin(), connectionPlugin()],
})
```

First-party packages add focused capabilities without bloating the core engine.

::note
Install only the package you need. There is no “all features” base package.
::

[Learn more → Going Deeper](/guides/extensions-and-middleware)
:::

::

## Five things to remember

::accordion
::accordion-item{label="The engine owns board state" icon="i-lucide-circle-help"}
Camera, nodes, selection, interaction, snap guides, and command events all live there.
::

::accordion-item{label="Nodes are records, not components" icon="i-lucide-circle-help"}
The engine stores plain data. Vue components render that data later.
::

::accordion-item{label="Commands are the mutation boundary" icon="i-lucide-circle-help"}
That is why history, command guards, and events can stay consistent.
::

::accordion-item{label="Rendering is layered" icon="i-lucide-circle-help"}
The board shell handles positioning and interaction. Your renderer focuses on content.
::

::accordion-item{label="Features stay optional" icon="i-lucide-circle-help"}
History, connections, minimaps, and selection helpers are all opt-in.
::

::
