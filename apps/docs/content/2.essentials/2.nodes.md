Nodes are immutable records that describe spatial objects on the board. The first release uses the JSON Canvas node types: `text`, `file`, `link`, and `group`.

## CRUD operations

::tabs

:::tabs-item{label="Create" icon="i-lucide-plus"}

```ts
const node = engine.createNode({
  type: 'text',
  x: 100,
  y: 200,
  width: 260,
  height: 140,
  color: '5',
  text: 'Node',
})
```

Omit fields when the defaults are enough. Pass `id` when SSR, tests, or imported documents need deterministic node IDs.

::tip
New nodes are selected by default. Pass `select: false` when creating support nodes, such as a group wrapper, without replacing the current selection.
::
:::

:::tabs-item{label="Read" icon="i-lucide-search"}

```ts
const node = engine.getNode(id) // throws if not found
const maybe = engine.findNode(id) // returns null
const hit = engine.getNodeAt({ x: 100, y: 200 }) // topmost at point
```

In Vue, use the `useNodes()` composable for reactive access:

```vue
<script setup lang="ts">
const nodes = useNodes()
// nodes.value is ReadonlyMap<NodeId, BoardNode>
</script>
```

:::

:::tabs-item{label="Update" icon="i-lucide-pencil"}

```ts
engine.updateNode(nodeId, {
  text: 'Node',
})

engine.updateNode(nodeId, {
  x: 300,
  y: 400,
  width: 320,
  locked: true,
})
```

:::

:::tabs-item{label="Delete" icon="i-lucide-trash-2"}

```ts
engine.deleteNode(nodeId) // delete a specific node
engine.deleteSelected() // delete all selected nodes
```

::warning
Deleting a group node also deletes all its descendants. If the connections plugin is installed, edges connected to deleted nodes are removed automatically.
::
:::

::

## Node input fields

::field-group
::field{name="id" type="NodeId" default="auto UUID"}
Auto-generated. Pass your own for deterministic scenes (SSR).
::

::field{name="type" type="'text' | 'file' | 'link' | 'group'" default="'text'"}
JSON Canvas node type. Use renderers to customize how supported node types look.
::

::field{name="x, y" type="number" default="0"}
World-space position (top-left corner).
::

::field{name="width, height" type="number" default="240 x 160"}
Dimensions in world units. Respects `NodeConstraints`.
::

::field{name="color" type="CanvasColor" default="undefined"}
Optional JSON Canvas color. Use preset IDs `'1'` through `'6'` or a six-digit hex color such as `'#3b7de0'`.
::

::field{name="locked" type="boolean" default="false"}
Prevents move, resize, and delete through interactions. Programmatic changes still work.
::

::field{name="visible" type="boolean" default="true"}
Hidden nodes are excluded from hit testing, bounds queries, `selectAll()`, and rendering. They can still be read directly by ID.
::

::field{name="parentId" type="NodeId" default="undefined"}
Parent group node for hierarchy. See the [group nodes guide](/guides/group-nodes).
::

::field{name="select" type="boolean" default="true"}
Selects the new node after creation. Pass `false` to leave the current selection unchanged.
::
::

## Moving and resizing

```ts
engine.moveNode(nodeId, 50, -20) // right 50, up 20
engine.translateSelectedNodes(10, 0) // nudge all selected right
engine.resizeNode(nodeId, 'se', 40, 30) // expand south-east
```

`translateSelectedNodes` handles group hierarchy. When a group moves, children follow. When a moved group fully contains another visible unlocked node's final bounds, the engine reparents that node into the group.

Resizing uses eight compass handles: `n`, `ne`, `e`, `se`, `s`, `sw`, `w`, `nw`. Hold :kbd{value="shift"} during interactive resize for aspect-ratio locking.

## Z-order, locking, and duplicating

```ts
engine.bringToFront(nodeId) // move to top
engine.sendToBack(nodeId) // move to bottom
engine.lockNode(nodeId) // block interactions
engine.unlockNode(nodeId) // allow interactions again
engine.duplicateNodes([nodeA, nodeB], { x: 20, y: 20 })
engine.copySelected() // internal clipboard
engine.pasteClipboard({ x: 20, y: 20 })
```

::note
The clipboard is internal to the engine — it does not use the system clipboard.
::

## Colors

Node colors live on `node.color`, not inside a generic payload.

```ts
engine.updateNode(nodeId, { color: '6' })
engine.updateNode(nodeId, { color: undefined })
```

The default Vue renderer resolves colors into themed border, fill, label, and selection variables. JSON Canvas export writes the same value to the top-level node `color` field.

| Preset | Default label |
| ------ | ------------- |
| `'1'`  | Rose          |
| `'2'`  | Amber         |
| `'3'`  | Citron        |
| `'4'`  | Moss          |
| `'5'`  | Azure         |
| `'6'`  | Violet        |

Use the built-in selection toolbar when users should batch-apply colors to selected cards and groups.

::collapsible

### Seeding with initial nodes

For SSR or deterministic scenes, pass `initialNodes` when creating the engine:

```ts
import { asNodeId } from '@lupinum/board-core'

const engine = createBoardEngine({
  initialNodes: [
    {
      id: asNodeId('node-1'),
      type: 'text',
      x: 0,
      y: 0,
      width: 240,
      height: 160,
      text: 'Node',
      color: '5',
      zIndex: 1,
      locked: false,
      visible: true,
    },
  ],
})
```

::

### Node events

```ts
engine.on('node:created', (node) => console.log('Created:', node.id))
engine.on('node:updated', (node, prev) => console.log('Updated:', node.id))
engine.on('node:deleted', (id, prev) => console.log('Deleted:', id))
engine.on('node:moved', (node, delta) => console.log('Moved:', delta))
engine.on('node:resized', (node, prev) => console.log('Resized:', node.id))
```

See the full [events reference](/events/events-and-subscriptions) for all available events.
