# Product

## Register

product

## Users

Vue and Nuxt product engineers building workflow editors, planning boards,
knowledge maps, whiteboard surfaces, and other domain-specific spatial tools.
They need to judge architectural fit quickly, ship a working board, and look up
exact behavior without reverse-engineering component state.

## Product Purpose

Vue Board provides a headless, command-driven board engine with thin Vue and
Nuxt integration. The documentation must make the model observable: what owns
state, how mutations commit, what persists, where optional features live, and
which trade-offs follow from those decisions.

## Brand Personality

Direct, deliberate, and technically honest. Confident through concrete behavior
rather than hype.

## Anti-references

- Generic component galleries that prove features exist without teaching them.
- Marketing pages built from repeated icon cards and unsupported superlatives.
- Documentation that hides required facts inside tabs, accordions, or demos.
- Dark terminal styling used as decoration rather than as a functional tool.
- Comparison tables designed to make every alternative look wrong.

## Design Principles

- Show the real system: examples run against workspace packages and expose state.
- Explain the constraint: state the decision, benefit, cost, and consequence.
- Keep one source of truth: human pages, raw Markdown, and agent output share content.
- Make the next action obvious: every page helps the reader decide, build, or verify.
- Prefer a small, consistent lab language over unrelated one-off demos.

## Accessibility & Inclusion

Target WCAG AA contrast, complete keyboard operation, visible focus, semantic
labels, responsive reading order, and reduced-motion alternatives. Interactive
content must also have a complete textual equivalent.
